# 국내기술개발 동향 분석 스킬 (`domestic-tech-trend`)

## ① 질의·요청 히스토리

- **2026-08-13** — "국내기술개발 동향 분석 스킬을 만들겠다. 사용자가 요청한 기술에 대해
  **멀티에이전트 3개**로 분야를 조사하고 작업 계획을 세운 뒤, 관련 **PDF·웹 자료를 다운로드**하고
  **MD 로 변환**하되 **각 문단마다 어디서 추출했는지 기본 정보**를 넣어라. 그리고 **사용자가 입력한
  템플릿·지침에 따라** 조사 내용을 바탕으로 문서를 작성해라."
- **2026-08-13** — 착수 확인 질의에 대한 사용자 선택:
  - 산출 위치: `research/<주제>/` (raw/·md/·plan.md·report.md)
  - 템플릿 입력: **MD 템플릿 파일 경로** (인라인 붙여넣기도 허용)
  - 조사 범위: **국내 중심 + 해외는 비교 근거로 최소**

## ② 확정 사양

### 2.1 파이프라인 (6단계, 건너뛰기 금지)

| 단계 | 내용 | 산출 |
|---|---|---|
| 0 착수 | 기술 범위·문서 용도·템플릿 경로 확인(부족분만 1회 일괄 질의), 폴더 생성 | `research/<슬러그>/` |
| 1 정찰 | **general-purpose 에이전트 3인을 한 메시지에 동시 투입** | 축별 후보 자료·핵심 사실·공백 |
| 2 계획 | 중복 제거·병합 → 계획 확정 → **사용자 승인** | `plan.md`, `sources.yaml` |
| 3 수집 | 실제 다운로드(멱등), 실패분 대체 배포처 탐색 → 수동 저장 유도 | `raw/`, `raw/manifest.json` |
| 4 변환 | 문단별 출처 마커가 박힌 MD 로 변환 | `md/S*.md`, `md/INDEX.md` |
| 5 작성 | 사용자 템플릿·지침대로 작성, 모든 사실에 마커 | `report.md` |
| 6 검증 | 인용 무결성 검사 후 각주 치환 | `report_final.md` |

**3단계를 실제로 수행하지 않고 4·5단계로 가지 않는다.** 기억으로 쓴 동향 문서는 산출물이 아니다.

### 2.2 정찰 에이전트 3인의 축 (겹치지 않게 분할)

- **A1 기술·시장 동향** — 기술 정의·분류, 발전 경과, 국내 시장규모·수요 전망, 로드맵상 위치
- **A2 연구·논문·특허** — 논문/특허 출원 추세, 주요 연구주체, 기술수준평가·격차, 핵심 난제
- **A3 산업생태계·정책·표준** — 국내 기업·공급망, 상용화 수준, 지원사업·법제도, 표준·인증

반환 형식 고정(조사질문 / 후보 자료 표 / 확인한 핵심 사실 / 이 축의 공백).
서로 어긋난 주장은 지우지 않고 `plan.md` "쟁점" 에 남긴다.

### 2.3 출처 마커 규격 (핵심 요구사항)

```
[출처ID:위치:문단번호]      예) [S03:p12:4]
```

- 위치: 쪽 있으면 `p<쪽>`, 웹 `web`, 한글 `hwpx`, 텍스트 `txt`
- `to_md.py` 가 **모든 문단 맨 앞**에 자동 부착
- 각 md 파일 머리에 출처 원장 YAML frontmatter: `source_id·title·publisher·year·kind·url·
  origin_file·fetched_at·sha256` → **md 조각 하나만 봐도 출처 복원 가능**
- 최종본은 마커를 각주 번호로 치환하되, `report.md`(마커 유지)를 검증 기준 원본으로 남긴다

### 2.4 스크립트

| 스크립트 | 역할 |
|---|---|
| `init_research.py` | `research/<슬러그>/{sources.yaml, plan.md, raw/, md/}` 골격 생성 |
| `fetch.py` | sources.yaml → raw/ 다운로드. 멱등, sha256·status 기록, `local:` 수동파일 채택 |
| `to_md.py` | PDF(PyMuPDF blocks)·HTML(HTMLParser)·HWPX(zip+XML)·TXT → 마커 부착 MD. `--tables` 로 표 추출 |
| `cite_check.py` | 유령 인용 / 원문 겹침 / 무출처 수치 문단 / 미사용 출처 검사 (유령 인용 시 exit 1) |
| `common.py` | 마커 정규식, sources/manifest I/O, 슬러그·정규화·노이즈 판정, UTF-8 stdout |

### 2.5 규칙

- 자료 신뢰도 등급: ①정부·출연연·통계·공시 ②학술논문·특허 ③협회·컨설팅 ④기업·언론.
  값이 엇갈리면 상위 등급을 본문에, 나머지는 각주 병기.
- 해외 자료는 비교 근거로만, 기준연도·측정조건이 다르면 비교하지 않고 각각 병기.
- 근거를 못 찾은 문장은 마커를 **지어내지 않고** `[근거미확보]` 로 남겨 사용자에게 보고.
- `.hwp` 첨부는 CLAUDE.md 규칙대로 `.hwpx` 로 먼저 변환.
- `research/*/raw/` 는 `.gitignore` 대상(저작권·용량). `md/`·`plan.md`·`report.md` 는 커밋 가능.

## ④ 미결/후속

- **스캔 PDF(이미지) OCR 미지원** — 현재는 "추출된 본문 없음" 으로 알리고 대체 자료를 찾는다.
  필요해지면 OCR 단계 추가 검토.
- **JS 렌더링 페이지** — 자동 수집 불가. 수동 저장(`local:`) 경로로 우회 중.
- **PDF 물리 쪽번호 ≠ 인쇄 쪽번호** — 마커의 `p` 는 파일 순번. 참고문헌에 쪽수를 적을 때 수동 확인 필요.
- `rnd-proposal-writer` 1-2절 지침을 템플릿으로 쓰는 경로는 아직 실사용 검증 전.
- webapp 파이프라인과의 연결(조사 결과를 웹서비스 입력으로) 미검토.
