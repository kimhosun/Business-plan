# 사양서 — 확인 필요 부분 빨강 표기(한글 변환 시)

## ① 질의·요청 히스토리
- 2026-08-13: "실적이나 내용 확인이 필요한 부분은 한글파일 변환할 때 붉은색으로 표기해줘."
  - 식별 방식(AskUserQuestion): **AI 변환 시 자동 마킹** 선택(플레이스홀더 패턴/사용자
    지정 마커/특정 절 전체는 미선택).
  - 표기 스타일: **글자색만 빨강**(하이라이트·[확인] 문구 미선택).

## ② 확정 사양
- **마커 규약**: 확인이 필요한 구간(실적 수치·기관 고유명사·특허/등록번호·인명·날짜·금액 등
  제반사항·RFP·입력에 근거가 없어 사람이 검증해야 하는 값)을 짝 마커
  `[[확인]]…[[/확인]]` 로 감싼다. 마커는 **본문 값 텍스트만** 감싸고 선두 개조식 마커
  (□·○·- 등)나 문단 전체를 감싸지 않는다.
- **AI가 자동 마킹**: 변환(convert)·채팅(chat)이 본문을 쓸 때 위 마커를 붙인다. 기존
  규칙의 `[○○ 확인 필요]` 자리표시도 `[[확인]]…[[/확인]]` 로 감싼다.
- **빌드 시 빨강 처리**: 최종 hwpx 빌드 후처리에서 마커 구간의 run 을 글자색 빨강
  (`#FF0000`)으로 바꾸고 **마커 문자는 제거**한다. 글꼴·크기는 원래 run 것을 유지
  (돋움체 12pt 본문 / 돋움 8pt 표셀 → 색만 빨강).
- **환경변수 게이트**: `HWPX_VERIFY_MARKS`(웹 빌드 기본 ON). 순수 왕복(pure)·구조편집
  경로에서는 OFF(문단 수 불변이라 좌표는 안 흔들리지만 일관성 위해 pure 목록에 포함).
- **무손실 왕복 불변**: 마커가 없으면 완전 무동작(no-op). 마커가 있는 문단만 run 을
  분할하므로 다른 문단·레이아웃은 불변.

## ③ 구현 상태 (완료 2026-08-13)
- 후처리: [hwpx_common.py](.claude/skills/hwpx-yaml-roundtrip/scripts/hwpx_common.py)
  `apply_verify_marks(hwpx, color="#FF0000")` — (1) 마커를 가진 run 의 charPrIDRef 집합을
  모아 header.xml 에 각 원본 charPr 의 **빨강 변형(textColor 치환)** 추가, (2) 각 section
  의 마커 run 을 [정상|빨강|정상] run 으로 분할하고 마커 제거, (3) 잔여 마커 문자열
  일괄 제거(짝이 run 을 넘어가는 예외 방지). 마커 상수 `_VERIFY_OPEN`/`_VERIFY_CLOSE`.
- 배선: [yaml2hwpx.py](.claude/skills/hwpx-yaml-roundtrip/scripts/yaml2hwpx.py) restore
  가 `HWPX_VERIFY_MARKS` 켜지면 **모든 후처리 뒤 맨 마지막**에 호출(글꼴/표/내어쓰기 후
  색만 덮음). [pipeline.py](webapp/backend/pipeline.py) restore 가 기본 ON(setdefault),
  pure=True 목록에 포함해 OFF.
- AI 마킹: [claude_service.py](webapp/backend/claude_service.py) `_VERIFY_MARK_RULE`
  공용 지시를 `_CONVERT_SYSTEM`·`_CHAT_SYSTEM` 에 반영(근거 없는 값은
  `[[확인]]…[[/확인]]` 로 감싸도록).

## ④ 미결/후속
- 웹 UI(입력/변환 결과 미리보기)에는 `[[확인]]…[[/확인]]` 마커가 그대로 보인다 — 어떤
  부분이 검증 대상인지 눈에 띄는 이점이 있어 유지. 화면에서 숨김/색표시가 필요하면
  프론트에서 마커 파싱해 렌더하는 개선을 별도 논의.
- 마커가 여러 run 에 걸쳐 분할되는 극단 케이스는 색이 일부만 적용될 수 있음(AI 생성
  문단은 단일 run 이라 실제로는 발생 안 함). 잔여 마커는 일괄 제거로 항상 지워짐.
- 표(엑셀형 그리드) 셀에 직접 입력한 값에는 AI 마킹이 없다 — 필요 시 사용자가 셀
  텍스트에 마커를 직접 넣으면 빌드에서 동일하게 빨강 처리됨(후처리는 표 셀 run 도 스캔).
