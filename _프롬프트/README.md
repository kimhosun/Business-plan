# 절별 작성 프롬프트 모음 (2026 SPR 사업계획서 근거)

구조화한 9개 사업계획서(01·02·03·04·05·07·08·10·11)의 **각 절 실제 내용**을 참조해,
동일한 절을 **새 과제로 작성할 때 쓰는 프롬프트**를 절(節)별로 만든 모음입니다.
각 프롬프트는 그 절의 목적·공통 구성(필수 포함요소)·문체 규칙·문서별 편차·참고 경로를 담고,
맨 아래 "작성 지시"의 `{과제명}·{키워드}·{기관}` 자리표시만 채워 LLM에 입력하면 됩니다.

- 공통 형식: [`_TEMPLATE.md`](_TEMPLATE.md)
- 절 색인(원자료): [`../_절색인.json`](../_절색인.json) — 라벨별 문서·경로 매핑
- 참조 규칙: 참고 문서의 **구조·요소·톤만 모방**하고 문장·수치는 복사하지 않음(각 프롬프트에 명시).

## 사용법
1. 쓰려는 절의 프롬프트 파일을 연다(예: 2-1이면 `2-1_최종목표.md`).
2. "작성 지시"의 `{…}`에 새 과제 정보를 채운다.
3. 전체를 LLM에 입력한다. 필요하면 "참고 자료" 경로의 실제 절 MD(`../NN/세부/...`)를 함께 열어 톤을 참고한다.
