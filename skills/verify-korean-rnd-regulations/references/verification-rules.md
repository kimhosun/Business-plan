# 검증 규칙과 보고서 스키마

## 출처 우선순위

1. 국가법령정보센터의 기준일 현재 시행 중인 법률·시행령·시행규칙·행정규칙 통합본문
2. 소관 부처의 고시·예규·공고 원문과 첨부파일
3. 전문기관의 해당 세부사업 공고·RFP·협약 서식·규정 게시판
4. IRIS·RCMS·ZEUS·i-Tube 등 공식 시스템 안내
5. KISTEP·전문기관의 공식 안내서와 연구보고서

5순위 자료로 1~3순위 규정의 시행 상태나 법적 의무를 대체하지 않는다. 블로그, 뉴스, 법률정보 재게시 사이트, 검색엔진 요약은 최종 근거로 사용하지 않는다.

## 날짜 판정

- `공포·발령일 <= 기준일 < 시행일`: 시행예정
- `시행일 <= 기준일`이고 폐지·실효되지 않음: 현행 후보
- 여러 조문의 시행일이 다르면 인용 조문별 시행일을 판정
- 법령 페이지에 미래 시행본이 기본 표시되면 기준일에 맞는 시행일자를 명시적으로 선택
- 연차 공고·가이드: 게시일뿐 아니라 적용 사업연도와 공고번호를 확인
- 협약 시점 규정 적용 문구와 경과조치가 있으면 최신 규정보다 우선할 수 있으므로 별도 표시

## 내용 대조 항목

- 제명과 약칭
- 규정 종류와 소관기관
- 공포·발령번호, 공포·발령일, 시행일
- 폐지, 전부개정, 제명변경, 후속 규정
- 인용 조문과 별표·별지 번호
- 금액, 비율, 기간, 기한, 승인·보고 조건
- 기관 유형별 예외와 영리기관 특례
- 적용 사업, 전문기관, 과제 선정·협약연도
- 시행예정 개정과 경과조치

## 판정 경계

- `historical`: 공식 페이지는 열리지만 적용연도·접수기간이 끝난 과거 공고·수요조사·가이드. 페이지의 현재 접근 가능성과 문서의 시의성을 구분한다.
- `conditional`: 대상 사업과 규정은 식별됐지만 기관 유형, 협약연도, 금액구간 등 명시된 조건의 충족 여부가 남은 경우.
- `undetermined`: 세부사업명·공고번호·협약 등 적용성을 판단할 식별자료 자체가 없는 경우.
- `source_match=partial`: 올바른 기관·문서군의 목록 또는 상위 안내지만 인용한 조문·첨부의 직접 원문은 아닌 경우.
- `source_match=mismatch`: 다른 사업·연도·문서이거나 홈페이지가 특정 통보문·승인문을 대신하는 경우.
- 중단 조건이 일부 항목에만 해당하면 확정 가능한 항목의 감사를 계속하고, 막힌 항목만 `undetermined` 또는 `unable_to_verify`로 보고한다.
- 상태별 건수는 파일별 인용 발생 건수를 기본으로 하되, 별도로 고유 URL 수와 고유 규정·문서 수도 함께 제시한다.

## 전체 감사표 필수 열

| 열 | 내용 |
|---|---|
| 파일·줄 | 인용 위치 |
| 문서 표기 | 현재 파일의 규정명·주장 |
| 유형 | 법률·시행령·고시·예규·공고·가이드·시스템 |
| 최신성 | `currency` 판정 |
| 적용성 | `applicability` 판정과 과제 식별 근거 |
| 출처 일치 | `source_match` 판정 |
| 공식 원문 충돌 | `official_source_conflict` 여부와 상충 문구 |
| 기준일 현행본 | 현행 제명·번호·시행일 |
| 내용 대조 | 조문·수치·적용 범위의 일치 여부 |
| 시행예정 | 시행일과 영향 또는 없음 |
| 조치 | 유지·링크교체·문구수정·삭제·과제자료요청 |
| 공식 근거 | 직접 원문 링크 |

## 최소 품질 기준

- `currency=current` 판정마다 기준일과 직접 원문 링크가 있음
- 미래 시행본을 현행으로 표시한 항목이 없음
- 숫자 주장은 해당 조문·별표까지 확인함
- 동일 규정의 여러 URL을 하나의 현행본으로 묶되 파일별 적용 문구는 각각 검토함
- 실제 공고가 없으면 일반 규정만으로 `CURRENT`를 단정하지 않고 과제별 확인 필요를 표시함
- 링크가 유효해도 적용기관이 다르면 불일치로 판정함
- 공식 현행 원문 자체의 낡은 교차참조는 조용히 수정하지 않고 충돌로 기록해 기관 확인을 요청함
