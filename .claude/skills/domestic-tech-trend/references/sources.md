## 자동 다운로드가 막히는 전형적 경우

- **로그인/회원가입 게이트** — ITFIND, DBpia, KIPRIS 상세
- **JS 로 본문을 그리는 페이지** — 받아도 빈 HTML. `to_md.py` 가 "추출된 본문 없음" 으로 알린다
- **스캔 PDF(이미지)** — 텍스트가 안 나온다. OCR 은 이 스킬 범위 밖이므로 사용자에게 알린다
- **뷰어 전용 문서(HWP 뷰어·플래시)** — 다운로드 링크를 따로 찾는다

→ 이때는 사용자에게 **정확한 URL 과 파일명을 알려주고 브라우저로 직접 저장**하게 한 뒤,
`sources.yaml` 항목에 `local: raw/<파일명>` 을 적고 `fetch.py` 를 다시 돌린다.

## 자료 신뢰도 등급 (문서에 인용할 때 이 순서로 우선)

1. **정부·출연연 공식 보고서, 국가통계, 공시** — 수치의 1차 근거
2. **학술논문(KCI 등재 이상), 특허 원문** — 기술적 사실의 근거
3. **협회·컨설팅 보고서** — 시장규모 추정치. "누가 어떤 방법으로 추정했는지" 함께 적는다
4. **기업 보도자료·언론기사** — 사실 확인용 보조. 단독 근거로 쓰지 않는다

같은 수치가 자료마다 다르면 **가장 상위 등급 값을 본문에 쓰고, 차이 나는 값은 각주로 병기**한다.
