# 출처 마커 규격

## 형식

```
[출처ID:위치:문단번호]
```

| 자리 | 뜻 | 예 |
|---|---|---|
| 출처ID | `sources.yaml` 의 id. 대문자 1자 + 2~3자리 숫자 | `S03` |
| 위치 | 쪽수가 있으면 `p<쪽>`, 웹은 `web`, 한글문서는 `hwpx`, 텍스트는 `txt` | `p12` |
| 문단번호 | 그 위치 안에서 몇 번째 문단인지 (1부터) | `4` |

정규식: `\[([A-Z]\d{2,3}):([^\]\s:]+):(\d+)\]`

## 변환본(md/)에서

`to_md.py` 가 **모든 문단 맨 앞**에 붙인다. 문단 본문은 마커 뒤 한 칸 띄고 시작한다.

```markdown
## p12

[S03:p12:1] 국내 고체산화물 수전해 기술은 2020년대 초 실증 단계에 진입하였다. …

[S03:p12:2] 다만 스택 수명은 해외 선도기업 대비 …
```

파일 머리 YAML frontmatter 에 원장이 들어간다 — `source_id · title · publisher · year ·
kind · url · origin_file · fetched_at · sha256`. **md 파일 하나만 떼어 봐도 출처가 복원된다.**

## 작성 문서(report.md)에서

본문 문단 끝에 근거 마커를 그대로 옮겨 붙인다. 여러 근거면 이어서 쓴다.

```markdown
국내 SOEC 스택 기술은 2023년 기준 5kW급 실증까지 도달했으나, 상용 기준인 수명 4만 시간에는
미치지 못한다. [S03:p12:2][S07:p4:1]
```

원문을 그대로 옮기면 인용부호를 쓴다.

```markdown
> "스택 열화율은 시간당 1.2%/1,000h 수준으로 …" [S03:p31:5]
```

**마커를 지어내지 않는다.** 코퍼스에 없는 마커는 `cite_check.py` 가 `[X] 코퍼스에 없는 인용`
으로 잡아낸다. 근거를 못 찾은 문장은 마커 대신 `[근거미확보]` 를 남기고 사용자에게 보고한다.

## 최종본에서 마커를 사람이 읽는 각주로 바꾸기

납품용 문서는 마커를 그대로 두지 않는다. 문서 말미에 참고문헌을 만들고 마커를 번호로 치환한다.
치환은 **`cite_check.py` 를 통과시킨 뒤 마지막에** 한다 (마커를 지우면 검증이 불가능해진다).

```
report.md          ← 마커 유지. 검증·수정의 기준 원본
report_final.md    ← 마커를 [1], [2] … 로 치환하고 참고문헌 절 추가
```

참고문헌 표기(국내 관행):

```
[1] 한국산업기술기획평가원, 「2025 산업기술 R&D 로드맵 — 수소」, 2025.3, p.12.
[2] 홍길동 외, "고체산화물 수전해 스택 열화 거동", 한국수소및신에너지학회 논문집, 34(2), 2023, pp.4-5.
```

## 검증

```bash
python cite_check.py --dir research/<주제> --doc research/<주제>/report.md --strict
```

- **유령 인용**: 코퍼스에 없는 마커 → 반드시 고친다 (종료코드 1)
- **낮은 겹침**: 인용한 문단과 원문의 어절 겹침이 낮음 → 인용 위치가 틀렸을 가능성
- **무출처 주장**: 연도·%·금액이 있는데 마커가 없는 문단 → 근거를 붙이거나 표현을 낮춘다
- **미사용 출처**: 받아놓고 안 쓴 자료 → 정말 불필요한지 확인
