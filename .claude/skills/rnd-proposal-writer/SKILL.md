# 연구개발계획서 절별 작성 스킬 패밀리 (rnd-write-*)

정부 R&D **연구개발계획서(사업계획서)** 를 표준 목차의 **절(節) 단위**로 작성하기 위한 스킬 모음의 인덱스다.
각 하위 스킬은 3개 실제 사업계획서를 참조해 **내용(과제 주제)은 새로 쓰되 문체·어감·구성·정량화 관행은 원본을 따르도록** 안내한다.

## 참조된 3개 사업계획서 (문체 학습 원천)
- **D1** — 해상 환경·선체 응답 계측 기반 선체 건전성 관리 디지털 트윈 시스템 개발
- **D3** — 15MW급 고정식 해상풍력 프리파일링 자켓 지지구조 운송·설치 공법 개발(실증형·대형 컨소시엄)
- **D11** — 대형 액화 CO2 저장 탱크 용접 후열처리 대체 기계적 응력 완화 공법 개발
원문 절별 트리: `참조문서/result/{문서}_절별/` (스킬마다 해당 절 원본 경로를 명시)

## 공통 문체 규칙 (전 절 공통)
- **개조식 명사형 종결**: "~개발/구축/수립/검증/확보/도출/함/음". 서술형 남발 금지.
- **마커 계층**: `□/[대괄호 머리] → ㅇ(◦) → -(—) → ·` 순, 절 내부에서 일관 유지. 번호는 `(1)(2)`, `①②`, `가.나.`.
- **강한 정량화**: 목표·근거에 수치+단위(MW·mm·%·톤·건수·CAGR)와 완충어(약/이상)를, 그림·표엔 `< 제목 >` 캡션 + `(Source : 기관, 연도)`.
- **약어·기관명**: 최초 등장 시 정의, 참여기관 정식명 괄호 병기.
- **원문 베끼기 금지**: 특정 문서 문장 그대로 옮기지 말 것(주제는 새로 씀). 허위·과장 수치 금지.
- **PDF 추출 잡음 무시**: 원본은 표가 줄 단위로 평탄화되고 이미지 해석문이 섞여 있음 — 레이아웃이 아니라 문체·구성만 모방.

## 참고 파일 번들 (references/)
공통 원칙과 세부 절별 상세를 분리한 경량 참고 파일이 `references/`에 있다. 각 세부 절 스킬(`rnd-write-*`)과 병행해 참조한다.
- `references/00_공통_작성원칙.md` — 전 절 공통 문체·마커·정량화·표·정합성·금지 규칙(§0~§9). 세부 절 파일이 `[공통원칙 §N]`으로 인용.
- `references/절_*.md` — 세부 절 19개 상세(표준 골격 + 문서별 변형 + 예문 + 체크리스트 + 원본 경로). 공통 규칙은 §번호 인용만 하고 절 고유 정보에 집중.
- 목록: `references/README.md`.

## 전체 계획서를 순서대로 작성할 때
표준 목차 순서로 위 스킬을 차례로 적용한다: 요약문 → 1-1·1-2·1-3 → 2-1·2-2·2-3 → 3-1·3-2·3-4(·3-5) → 4 → 5-1·5-2·5-3·5-4 → 6 → 7 → 8.
**절 간 정합성**을 유지하라: 2-1 성능지표 = 2-2 차년도 목표 = 2-3 일정/결과물, 8장 예산 합계 = 기관별 합. 과제 규모·유형(실증형/연구형, 참여기관 수)에 따라 밀도(D1 장문 ~ D11 단문)와 선택 절(3-5, 표준화 등)을 조정한다.

## 시작 질문(과제 정보 수집)
새 계획서/절 작성 요청 시 최소한 다음을 확인: 과제명·핵심기술, 사업 유형(연구형/실증형), 총 기간·단계·차년도, 참여기관(주관/공동/수요), 정량 최종목표(수치), 예산 규모.
