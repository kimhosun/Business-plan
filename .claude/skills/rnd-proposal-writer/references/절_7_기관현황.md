# 절_7 연구개발기관 현황

**대응 스킬**: `rnd-write-7-org`
공통 문체·서식은 `00_공통_작성원칙.md`를 `[공통원칙 §N]`으로 인용. 여기서는 7장 고유의 표 항목 구성·판단 기준·체크리스트만 다룬다.

> 이 장의 성격: **자유 서술이 아니라 정형 서식(표) 칸 채우기**가 대부분. 서술 칸(개발내용 요약·사용용도 등)만 개조식 명사형 [공통원칙 §1]. 항목 누락 없이 표 골격을 갖추는 것이 문체 모방보다 우선.

## 1. 표준 골격 (3문서 공통)
위에서부터 순서대로. 참여기관 수만큼 7-1(2)와 참여연구자 행이 반복.

### 7-1. 연구책임자 및 참여연구자 등 현황
- **(1) 주관연구개발기관책임자(연구책임자)** — 소항목 가~사를 표로:
  - **가. 인적사항**: 국·영문 성명 / 국적 / 국가연구자번호 / 기관·부서·직위 / 전화·휴대·전자우편 / 주소(우편번호)
  - **나. 학력**: 취득연월 / 학교 / 전공 / 학위 / 지도교수 (최근순) + 최종학위 논문명
  - **다. 경력**: 기간 / 기관 / 직위 / 비고 (최근순, "~현재")
  - **라. 국가연구개발 실적 및 현황**: 중앙행정기관(전문기관) / 세부사업 / 과제명 / 주관기관 / 전체기간(참여기간) / 역할(책임자·연구자) / 비고(신청·수행중·완료) / 당시 소속
  - **마. 대표 논문·저서 실적**: 구분 / 논문·저서명 / 게재지(권,쪽) / 게재연도 / 역할 / ISSN / 비고(피인용·IF)
  - **바. 지식재산권 출원·등록 실적**: 구분(특허/프로그램) / 명칭 / 국가 / 출원·등록일 / 번호·등록자수 / 비고(출원/등록)
  - **사. 그 밖의 수상경력 등 대표 실적**: 구분 / 실적명 / 내용요약 / 실적연도
- **(2) 공동연구개발기관책임자** — `[공동연구개발기관N – 기관명]` 또는 `(2-1) 기관명` 헤딩 아래 가~사 골격 **동일 반복**. (D3는 `[수요기업N – 기관명]`도 별도)
- **(3) 참여연구자 및 연구지원인력**
  - **가. 참여연구자 현황**(대형 표): 번호 / 소속기관(역할) / 신규구분(청년의무·추가·기타)·기존·시간선택·외부 / 성명(국적) / 직위 / 생년월일(성별) / 학위·전공·취득년도 / 담당역할 / 참여기간 / 본과제 인건비계상률(A) / 타 국가R&D 계상률(B) / 합계(A+B) / 참여과제수(3책/5공)
  - **나. 연구지원인력 현황**
  - **다. 여성 참여연구자 비율**: 총원 / 여성수 / 비율(%)
  - **라. 연구개발기관이 아닌 관계 기관** (없으면 "- 해당없음")

### 7-2. 연구시설·장비 보유현황
- ※ 안내: "ZEUS 등록번호 있으면 ZEUS번호, 없으면 자산등록번호 기재"
- 표 열: 보유기관 / 시설·장비명(ZEUS·자산번호) / 구매일자 / 구매금액(천원) / 활용시기 / (내용연수) / 연구개발 중 사용용도 / 현물부담 반영("○") / 현물부담금액(천원)
- 기관별로 묶어 나열. 상용 SW(ABAQUS·ANSYS·NASTRAN·Matlab 등)·서버/클러스터·시험장비(만능재료·피로·충격시험기 등)를 사용용도와 함께.

### 7-3. 연구개발기관 일반 현황
- **(1) 일반 현황**
  - **ㅇ 비영리기관**: 사업자·법인등록번호 / 대표자(성명·국적) / 기관유형 / 지원담당자(성명·부서·직위·전화·전자우편·팩스)
  - **ㅇ 기업**(단위 천원·%): 사업자·법인등록번호 / 대표자 / 기업유형(중소·중견·대기업) / 최대주주 / 설립연월일 / 주생산품목 / 상시종업원수 / 직전년도 매출 / 매출 대비 R&D비율 / **재무분석 3개년**(부채비율·유동비율·자본총계·자본금·영업이익·이자보상비율)
- **(2) 국가R&D·기술이전·사업화·보유특허 실적** *(D1·D11 수록, D3 생략 가능)*
  - **o 국가R&D 주요 수행실적**: 기관명 / 과제명 / 주관기관 / 기간(참여기간) / 개발내용(핵심 요약) / 중앙행정기관(전문기관) / 비고(수행중·완료) / 역할(주관·공동)
  - **o 동 과제 관련 기보유 지재권 출원·등록 현황**: 소유권자 / 명칭 / 국가 / 출원·등록번호·일
  - **o 기술이전 실적 / o 사업화 실적** (없으면 표 골격 + 각주 `1」2」3」`만 유지)

## 3. 절 특유 문체 포인트 (공통과 다른 점만)
- **표 셀 채우기가 원칙**: 대부분 칸은 고유명사·날짜·수치. 창작 서술 금지. 마커·종결형 일반은 [공통원칙 §1·§2].
- **개발내용 요약 칸**: 번호·불릿으로 2~3개 나열, 슬래시로 병렬 압축(예: "A 개발 / B 모니터링 / DT 시스템 개발").
- **전문기관 약어 괄호 표기**(§5 확장): 산업통상자원부(KEIT/KETEP/KIAT) / 해양수산부(KIMST) / 과학기술정보통신부(연구재단·NST) / 국토교통부(KAIA). 세부사업명은 정식 명칭.
- **역할·상태 어휘 고정**: 역할=책임자/연구자(연구책임자/참여연구자), 상태=신청/수행중(진행중)/완료, 기관역할=주관/공동(/수요).
- **정량 표기 세부**: 금액 천원, 기간 `YY.MM~YY.MM` 또는 `YYYY.MM.DD`, 논문은 게재지·권·쪽·ISSN·(선택)IF·피인용·FWCI. (일반 정량 규칙 [공통원칙 §3])
- **계층 마커 이 장 관행**: 대분류 `ㅇ`/`◦`, 실적 소분류 `o`, 인적사항 하위 `가.·나.·다.`, 절 `(1)(2)(3)`, 안내문 `※`, 각주 `1」 2」`.

## 4. 대표 예문 (3문서 발췌)
- **D1** — 국가R&D 개발내용 요약: "위성데이터 이미지 데이터 기반 최적 항로 개발 및 모니터링/DT 시스템 개발" → 개조식 명사형·슬래시 병렬 압축. 기업 재무는 부채·유동비율·자본총계를 3개년(2021~2023)으로.
- **D3** — 시설·장비에 실증 물자 포함, 현물부담 채움: "등부표 / 75,810 / 해상실증 수행 / ○ / 21,479". '사'항 사업화: "제주 한림 해상풍력 하부기초 제작·설치 및 상부 설치(2019~2024)" → 대형과제는 현물·사업화 실적 적극 기재.
- **D11** — 논문 비고에 정량 지표: "상위 JCR 6.0% (IF 5.5) / 피인용:1 / FWCI:0.46". 신청 단계 과제 비고 "신청", 주관기관·참여기간 명기 → 논문 경쟁력 JCR·IF·FWCI 정량화, 과제 상태 정확 구분.

## 5. 체크리스트 (7장 필수 요소)
- [ ] 주관 + 모든 공동(+수요)기관 책임자가 각각 가~사 7개 소항목을 갖췄는가
- [ ] 참여연구자 표에 인건비계상률(A/B/합계)·참여과제수(3책/5공)·신규구분이 모두 있는가
- [ ] 여성 참여연구자 비율(총원·여성수·%)이 참여자 표와 일치하는가
- [ ] 7-2에 ZEUS/자산등록번호·구매금액(천원)·사용용도·현물부담 컬럼이 있는가
- [ ] 7-3(1) 기업 현황에 재무분석 3개년(부채·유동비율·자본총계·이자보상비율)이 있는가
- [ ] 7-3(2) 국가R&D 실적에 역할(주관/공동)·비고(수행중/완료)·전문기관이 있는가
- [ ] 전문기관 약어(KEIT/KETEP/KIMST 등)·과제 상태 어휘가 통일됐는가
- [ ] 참여기관 목록·인건비계상률 합계가 3-1 역량표·8장 예산과 정합하는가 [공통원칙 §7]
