# 절 1-3 「관련 지식재산권·표준화 및 인증기준 현황」 상세

- **적용 절**: `### 1-3. 관련 지식재산권, 표준화 및 인증기준 현황 등`
- **대응 스킬**: `rnd-write-1-3-ip`
- **역할**: 과제 관련 **① 지식재산권(특허) 현황(자사/국내/국외), ② 국제표준화 활동, ③ 인증·선급 기준**을 **표 중심**으로 정리해 IP 지형·표준/규제 대응 근거 제시.
- 공통 규칙 [공통원칙 §1~§5]. 이 절은 특히 표 서식 [공통원칙 §4] 중심. 아래는 고유 내용만.

## 문서별 존재 형태(중요 — 유형 판단 먼저)
- **D3(해상풍력)**: 이 절을 **독립 절로 완비** → 본 절의 1차 모델.
- **D1(디지털트윈)**: 1장에 **독립 1-3 없음**(1-1·1-2로 종료). IP/표준은 타 장에서 다뤄질 수 있음.
- **D11(액화CO2)**: 1-3 미독립 → 표준/규제(IGC Code)·인증 필요성을 **1-2 배경·필요성 안에 편입**해 서술.
- **판단 기준**: 명시적 1-3 절이 요구되면 **D3 골격 기본**. 표준·인증이 필요성 논거 수준이면 D11식으로 1-2에 편입(→ `절_1-2` 참조).

## 표준 골격 — D3 기준
- `#### (1) (연구개발기관)` — 컨소시엄 보유 IP·표준·인증
  - `ㅇ 지식재산권(특허) 보유 현황` — 표: **No / 출원인 / 출원번호·일자 / 특허명**
  - `ㅇ 국제표준화(IEC 등) 활동 현황` — 표: **위원회 / 회의명(TC·WG·PT) / 주제 / 참석자(기관)**
  - `ㅇ 국제선급연합회(IACS) 정회원 선급 인증 기준` — 표: **기준명 / 보유기관** (선급 규칙 편·해양구조물 규칙 등)
  - `ㅇ 국내 주요 관련 특허` — 표: **특허내용 / 대표도** (상태·출원일·출원번호·등록번호·출원인)
- `#### (2) (참여기관/공동)` — 문서에 따라 생략·통합 가능
- `#### (3) (국외 경쟁 기관)` — `ㅇ 국외 주요 관련 특허`(국내와 동일 표, 출원인 국적 미국/PCT/중국 등 표기), (선택) 국제선급/인증 재정리

## 절 특유 문체 포인트
- **표 중심·서술 최소**: 표제·설명은 "~현황/~보유/~기준/~적용됨" 명사종결. 서술문은 표를 잇는 최소한만.
- **특허 표기 관행**:
  - 보유특허 표 4열(No·출원인·출원번호/일자·특허명). 등록/출원 상태를 일자에 붙임("2018.05.24. 등록", "10-2021-0076980 (2021.06.14)").
  - 특허명은 원어 명사구 그대로("일체형 해상풍력 자켓 지지구조물의 시공방법").
  - 국내/국외 주요 특허 개별 항목은 `▪특허명(출원인)` 머리 + `- 상태 : 등록`, `- 출원일자 : …`, `- 출원번호 : …`, `- 등록번호 : …` 항목형도 가능.
- **표준화 표기**: 기구·기술위원회 약어 — "IEC TC 88", "MT 12-1", "PT 61400-6", "WG 3", "IECRE". 주제·참석기관(예: 한국선급) 병기.
- **인증/선급 표기**: "국제선급연합회(IACS)", 선급 규칙을 "제1편 …제9편" 편 단위 및 "고정식/이동식 해양구조물 규칙"으로 열거. 코드는 약어 정의(IGC Code, PWHT) [공통원칙 §5].
- **대표도**: `대표도` 열/캡션 자리에 그림 링크 위치만 표시.

## 대표 예문(3문서)
- **D3 보유특허표**: "No 1 / 케이베츠 / 10-1865511 · 2018.05.24. 등록 / 일체형 해상풍력 자켓 지지구조물" → 4열 표, 등록상태를 일자에 붙임.
- **D3 표준화**: "IEC TC 88 — MT 12-1 출력성능 측정(한국선급) / PT 61400-6 타워·기초 / WG 3 해상풍력 설계요건 // IECRE WG 3SG550 인증기관 회의" → 위원회/회의명(약어)·주제·참석기관 표.
- **D3 인증**: "IACS 정회원 선급 인증 기준 / 선급 및 강선 규칙: 제1편 선급등록·검사 … 제9편 추가설비(한국선급) / 해양구조물 규칙: 고정식 해양구조물 규칙 …" → 기준명/보유기관 표, 규칙 편 단위 열거.
- **D11(1-2 편입 논거)**: "현행 IGC Code상 적용범위가 제한돼 50mm 이상 확장 적용·표준화·인증 체계가 미흡한 상황임" → 독립 1-3 대신 표준·인증 gap을 **필요성 논거**로.
