# 절 상세: 요약문

- **표준 절 제목**: `< 요 약 문 >` (※ "요약문은 5쪽 이내로 작성" 안내문 동반)
- **대응 스킬**: `rnd-write-summary`
- 공통 문체·서식은 [공통원칙 §1~§5]를 따르고, 여기서는 요약문 고유 서식만 기술한다.

## 표준 골격 (3문서 공통)
문서 맨 앞의 **정형 양식 칸 채우기**다. 자유 서술이 아니라 위→아래 순서로 각 칸을 개조식으로 채운다.

1. **관리정보 표** (각주번호 유지)
   - 세부사업명¹⁾ / 내역사업명²⁾ / 총괄연구개발 과제번호³⁾ / 연구개발 과제번호⁴⁾
   - 기술분류⁵⁾: **산업기술분류** + **국가과학기술표준분류** 각각을 분류명+비율(%)로, 3개 합계 100%(예: 50/30/20)
   - 총괄연구개발과제명⁶⁾ / 연구개발과제명⁷⁾
   - 전체 연구개발기간⁸⁾: `YYYY.MM.DD ~ YYYY.MM.DD` (필요 시 "(3년 9개월)" 병기)
   - 기술료: `징수[√] 비징수[ ]`
   - 총 연구개발비⁹⁾: `총 N천원 (정부지원연구개발비: N, 기관부담연구개발비: N, 지자체부담금 등: N)`
   - 연구개발단계¹⁰⁾: `기초[ ] 응용[ ] 개발[ ] 기타[ ]` 택1 √
   - 기술준비도(TRL)¹¹⁾: `착수시점[N] 종료시점 목표[N]`
   - 연구개발과제 유형¹²⁾ / 특성¹³⁾: 체크박스군 해당 항목 √
2. **연구개발 목표¹⁴⁾ 및 내용¹⁵⁾**
   - 최종 목표(1~2줄 명사형) + (선택) `전체 개발내용` 번호/ㅇ 목록
   - 단계/차년도별 **목표**, 이어서 같은 계층의 **개발내용**
3. **연구개발성과 활용계획 및 기대효과¹⁷⁾**
   - `[활용방안 및 기대효과]` / (분량 있으면) `[기대효과]`를 측면별 세분
   - `[기술기여도]`: **기관 × 연차별 기여도(%) 표**
4. **국문핵심어 / 영문핵심어** (각 **5개 이내**, 1:1 대응)

## 문서별 변형(밀도 택1) — [공통원칙 §6]
- **D1(디지털트윈, 장문)**: 2단계 × 각 2차년도, 목표·내용 상세. 활용방안 `□`대분류+`o`중분류+`-`설명, 기대효과 3개 "측면"(과학·기술/경제·사회/인프라) 세분, 기술기여도 표 7년차까지.
- **D3(프리파일링자켓, 상세)**: 최종목표 아래 `전체 개발내용 1~6` 번호목록+개념도. 2단계 × 각 3차년도. 기대효과 ㅇ 4줄 간결, 기관 7곳 기여도 표.
- **D11(LCO2탱크, 단문)**: 단계 구분 없이 [1~4차년도 목표]·[1~4차년도 개발내용]을 각 1~5줄 ㅇ 목록. 기대효과·기여도 각 2줄.
- **선택 기준**: 과제 규모·기간·참여기관 수에 따라 D1(장문)~D11(단문) 사이 밀도를 정한다. 소규모·짧은 기간이면 단계 없이 차년도만.

## 절 특유 문체 포인트
- **양식 칸 서식 그대로 유지**: 체크박스는 미기재 칸까지 원형(`[ ]`)을 남기고 해당 항목만 `√`. 각주번호(¹⁾²⁾…)·단위·괄호 형식 보존 — [공통원칙 §4].
- **정량 지표를 과제명·최종목표에 직접 박는다** — [공통원칙 §3]. 요약문은 심사자 첫인상이므로 규모·성과지표·공법명을 최종목표 1문장에 압축(예: "15MW급", "10% 이상 절감형").
- **목표와 개발내용은 동일 차수 계층으로 대응**시킨다([1차년도] 목표 ↔ [1차년도] 내용). 계층 불일치 금지 — [공통원칙 §7 목표 사슬]의 요약판.
- **5쪽 이내** 제약: 밀도를 과제에 맞춰 압축. 넘치면 측면 세분·번호목록을 줄인다.
- 핵심어는 과제 정체성 대표 명사구, 국·영문 1:1(예: 기계적응력완화 ↔ Mechanical Stress Relief) — [공통원칙 §5].

## 대표 예문 (3문서 발췌)
- **D1** 최종목표+번호분해: "…선체 구조 건전성 관리를 위한 디지털 트윈 시스템 개발 및 실선·모형 시험 기반 검증 / 1. Onboard 계측 데이터 기반 국부 응력 추정 및 장기 피로 손상도 예측 …"
  → 최종목표 1문장(명사형) 뒤 번호목록으로 세부 분해.
- **D1** 기대효과 측면: "[과학·기술적 측면] o 예방적 안전 감시 목적의 대형 구조물 디지털화 달성 — …"
  → `측면 → ㅇ표제 → - 근거` 3계층.
- **D3** 정량 압축: "ㅇ 15MW급 기간/비용 10% 이상 절감형 프리파일링 자켓 지지구조 운송/설치 공법 개발"
  → 규모·성과지표·대상을 한 줄에.
- **D11** 초간결 차년도: "[1차년도 목표] ㅇ MSR 적용 조건 도출 및 잔류응력 계측·해석 기반 구축 / [2차년도 목표] ㅇ 시험편 수준에서 MSR 잔류응력 저감 효과 정량 검증"
  → 단계 생략, 차년도별 한 줄 명사형.
