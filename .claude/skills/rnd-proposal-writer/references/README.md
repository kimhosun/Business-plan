# 연구개발계획서 작성 참고 번들 (references)

`rnd-proposal-writer` / `rnd-write-*` 스킬이 참조하는, **공통 원칙 + 세부 절별 상세**로 분리한 경량 참고 파일 모음.
세부 절 파일은 공통 규칙을 재서술하지 않고 `[공통원칙 §N]`으로 인용한다.
