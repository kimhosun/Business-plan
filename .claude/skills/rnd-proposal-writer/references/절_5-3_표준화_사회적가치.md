# 절 5-3 — 표준화 전략 / 사회적 가치 창출 계획

- **표준 절 제목**: "5-3. 표준화 전략"(D11 상세, D1 "해당사항 없음") + "사회적 가치 창출 계획"(D1 5-3 / D3 5-3 / D11 5-5, 절번호 문서별 상이·구성 공통)
- **대응 스킬**: `rnd-write-5-3-value`
- 공통 문체·서식은 `00_공통_작성원칙.md` 참조.

## 표준 골격

### 표준화 전략 (D11 모델)
- `◦ 표준화 목표 및 범위` — 목표(지침 개발+선급 개념승인 AIP 획득), 범위(시방서/평가 절차서/건전성 평가 기준)
- `◦ 선급/개념승인(AIP) 취득 및 기술 공신력 확보 전략` — 해석 절차 표준화, 선급 공동개발·협의, 실증데이터 기반 기술승인
- `◦ 선급 지침 제정 및 현장 제작 공정 시방서 개발` — 기술 가이드 초안, 표준 작업 시방서, 데이터 축적 유효성 검증
- 5단계 흐름 도식 곁들이는 관행: 개념설계→기본설계(AIP)→상세설계→실증·검증→표준화·인증

### 사회적 가치 창출 계획 (3문서 공통)
- (1) 사회적 가치 창출 계획
  - `o (개요)` — 창출할 가치 한 줄 정의
  - `o 추진전략(비전)` — **(직접적)** 수행 과정 발생 / **(간접적)** 확산·상용화 발생
  - `o 세부계획1,2,3,4` — 안전 근로환경/환경오염 예방/지역균등발전/대·중소 상생/일자리 중 3~4개
- (2) 사회적 가치창출 기대효과 — 정형 4축:
  - 대·중소기업 간 상생과 협력 / 양질의 일자리 창출 / 지역경제 공헌(이익의 지역 순환) / 환경의 지속가능성 보전

## 문서별 변형 (유형 택1)
- **표준화 전략**: D11은 AIP·선급 지침 획득이 성과라 두껍게. D1은 표준화 요소 없어 "- 해당사항 없음"으로 짧게. → **과제에 표준화 요소가 없으면 억지로 만들지 말고 "해당사항 없음"** (`[공통원칙 §6]`).
- **사회적 가치**: 절번호만 문서별로 다르고(D1 5-3/D3 5-3/D11 5-5) 내부 구성은 동일. (2) 기대효과 축은 과제 맥락에 맞춰 2~4축으로 변형(D1은 "환경 지속가능성/시장 견인" 등 1축 대체).

## 절 특유 문체 포인트
- **직접/간접 이분법 필수**: 사회적 가치는 반드시 (직접적)=수행 중 / (간접적)=확산·상용화 시로 나눔.
- **세부계획 콜론 표기**: "세부계획1 : …" 제목 + 하위 `-` 설명.
- **정부 사회적 가치 정형 어휘**를 (2) 축 제목에 그대로 사용: "양질의 일자리", "대·중소기업 간 상생과 협력", "지역경제 공헌/선순환", "환경의 지속가능성 보전", "탄소중립 전환", "안전한 근로 환경".
- 참여기관을 지역별로 묶어 인력양성·지역경제 효과 연계(예 "수도권/충청/경남 지역 인력양성").
- 표준화는 `◦ 제목 → — 소제목 → 본문` 마커. 개조식 종결·계층은 `[공통원칙 §1, §2]`.

## 대표 예문 (3문서)
- **D11 표준화**: "LCO2 탱크 제작 시 MSR 공법 적용 현장 가이드라인 수립, 파괴역학 기반 구조 건전성 평가(ECA) 절차 정립, 국내외 선급 지침 개발 및 인증 확보 목표" → 목표·범위 한 문장 압축 후 ◦ 전개.
- **D11 사회적 가치**: "— 직접적(수행 과정): 산학연-조선소 협력 기반 상생 구조 … / — 간접적(확산·상용화): LCO2 운반선 시장 확대에 따른 전후방 산업 동반 성장" → 직접·간접 정석.
- **D3 사회적 가치**: "o 세부계획3 : 국외 선점 기술 국산화로 대·중소기업 상생 … 해외 진출 기틀" + 기대효과 "o 대·중소기업 상생 / o 이익이 지역에 순환되는 지역경제 공헌" → 세부계획+4축.
- **D1 사회적 가치**: "(직접적) 선체 사전 파손 예측 유지보수로 … 인명 피해 최소화 할 수 있음" → 직접/간접 괄호 표기.
