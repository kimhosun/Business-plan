# 연구개발계획서 공통 작성 원칙 (전 절 공통)

`rnd-write-*` 세부 절 스킬과 절별 상세 파일(`절_*.md`)이 **공통으로 전제**하는 문체·서식 규칙이다.
세부 절 파일은 이 문서를 `[공통원칙 §N]` 으로 인용하고, 절 특유 사항만 따로 기술한다.

## §0. 정체성과 참조 원천
- 문서 종류: 정부 R&D **연구개발계획서(사업계획서)**. 심사자가 읽는 격식 있는 공식 문서.
- 문체 학습 원천 3종(원문: `참조문서/result/{문서}_절별/`):
  - **D1** — 해상 환경·선체 응답 계측 기반 선체 건전성 디지털 트윈(연구형, 중간 밀도)
  - **D3** — 15MW급 해상풍력 프리파일링 자켓 운송·설치 공법(실증형·대형 컨소시엄, 최다 밀도)
  - **D11** — 대형 액화 CO2 저장 탱크 응력 완화 공법(간결 밀도)
- **핵심 원칙: 내용(주제·수치)은 새로 쓰되, 어투·어감·구성·정량화·표 양식은 3문서를 모방.**

## §1. 문체·종결형
- **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- 근거·판단 문장은 반개조식 허용: `~가능함 / 기대됨 / 판단됨 / 필요함 / 예상됨`.
- 완결 서술문(“~한다/~이다”)의 남발 금지. 한 항목 1~3줄, 밀도 높게.

## §2. 마커·번호 계층
- 계층 순서: `□ 또는 [대괄호 머리말] → ㅇ(◦) → -(—) → ·`.
- 번호: `(1) (2)`, `① ②`, `가. 나. 다.`. 표 셀 안 체크·나열은 `ü / Ÿ / ⦁`(원문 관행).
- **한 절 안에서 마커 체계를 일관**되게 유지(문서별 스타일 중 하나를 택해 끝까지).

## §3. 정량화·근거 표기
- 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.
- 목표치엔 완충어 `약 / 이상 / 이내`를 관행적으로 동반(예: “10% 이상 절감”, “TRL 4→7”).
- 그림·표에는 `< 제목 >` 또는 `[ 제목 ]` 캡션과 `(Source : 기관, 연도)` 출처를 붙인다.

## §4. 표 서식 관행
- 상당수 절은 자유 서술이 아니라 **정형 표 채우기**다. 표의 열·행 구성과 코드·관계식(예: 예산 K=직접비, M=K+L)을 유지한다.
- 표 셀 안 텍스트도 개조식 명사구로 짧게. 표 하단 `※`·각주 `1) 2)`로 정의·기준을 명시.

## §5. 용어·기관명
- 영문 약어는 **최초 등장 시 정의**(예: PWHT, BIM, MSR, IEC, IACS, TRL/CRL).
- 참여기관은 정식 명칭, 본문 병기 시 괄호((케이베츠)·(서울대) 등). 역할 머리표는 `[주관/공동/수요기관 : 기관명]`.

## §6. 분량·밀도 선택
- 밀도 스펙트럼: **D1 장문 ~ D3 상세 ~ D11 단문**. 과제 규모·유형(연구형/실증형)·참여기관 수에 맞춰 택한다.
- 선택 절(실증설비 3-5, 표준화 전략 등)은 과제 성격에 맞으면 두껍게, 아니면 간략화하거나 “해당사항 없음” 관행을 따른다.

## §7. 절 간 정합성 (전체 작성 시 필수)
- **목표 사슬**: 2-1 정량 성능지표 = 2-2 각 차년도 목표 = 2-3 일정·주요 결과물.
- **예산 정합**: 8-1 총계 = 8-2 총괄표 = 기관별 합, 8-3 세부합 = 8-2 비목값.
- **기관·기간 정합**: 참여기관 목록·단계/차년도 수를 전 절에서 동일하게.

## §8. 금지사항
- 특정 참조문서의 문장을 **그대로 베끼기**(주제·문구는 새로 작성).
- **허위·과장 수치**, 근거 없는 목표.
- PDF 추출 잡음 재현: 원문은 표가 줄 단위로 평탄화되고 `> **이미지 해석**:` 문장이 섞여 있음 — **레이아웃 잡음이 아니라 문체·구성만** 모방.

## §9. 공통 작성 절차
1. **과제 정보 수집**: 과제명·핵심기술, 사업 유형(연구형/실증형), 총 기간·단계·차년도, 참여기관(주관/공동/수요), 정량 최종목표(수치), 예산 규모.
2. **골격 선택**: 해당 절의 표준 골격 + 문서별 변형 중 과제에 맞는 유형 택1(절별 파일 참조).
3. **개조식으로 채우기**: §1~§5 규칙 적용.
4. **점검**: 절별 체크리스트 + §7 정합성 확인.
