# 절 3-1. 기술개발 추진방법·전략

- **표준 절 제목**: 3-1. 기술개발 추진방법·전략
- **대응 스킬**: `rnd-write-3-1-strategy`
- 공통 문체·서식은 `00_공통_작성원칙.md`를 인용한다. 여기서는 이 절 고유 내용만 기술.

## 표준 골격 (3문서 공통 뼈대)
- **(1) 참여기관 역량 / 기술개발 방법** — 아래 두 형태 중 과제 성격에 맞게 택1
  - **형태 A(기관 역량 중심)**: `기관명 | 역할(주관/공동/수요) | 기관 역량·실적·추가 투자계획` 3열 표. 셀 안은 `ü`/`·` 불릿 2~4개.
  - **형태 B(개발 방법·흐름 중심)**: 개발 단계·주체를 열로 둔 개념표(예: `사업자 | 신공법·설계 | 검증 | 실증·사업화 | 수요기업`) 또는 로드맵 그림 + `①②③` 단계 서술.
- **추진방법·전략 서술** — 표 아래 `ㅇ` 개조식 불릿 6~10개(협력체계·정량지표 사전협의·수요기업 우선검증·차년도 검증계획·상용화·필요시 위탁).
- **협업체계/추진체계 개념도** — 순환·수렴 구조 다이어그램 1개(그림 자리 + 캡션).
- **(선택) 위험극복 방안** — `위험요소 | 위험극복 방법` 2열 표. 실증·안전관리형에서 권장.

## 문서별 변형 (유형 택1)
- **D1(연구형·형태 A)**: (1) 참여기관 역량 표 → (2) 추진방법·전략(개념도 + `ㅇ` 불릿 다수). 인력·자체SW·유사R&D 실적 중심.
- **D3(실증형·형태 B)**: (1) 기술개발 방법(단계·주체 흐름표 + `ㅇ` 불릿) → (2) **위험극복 방안 표**가 두드러짐(실증·안전관리형).
- **D11(간결형·로드맵)**: 연구개발 로드맵 그림 + `①②③` 단계 서술 → 기관별 역량표 + 협의체(LCO2 MSR) 협업 다이어그램.
- **판단 기준**: 실증·시공형이면 형태 B + 위험극복 표. 연구·SW형이면 형태 A. 단계가 명확한 요소기술 축적형이면 D11식 로드맵.

## 절 특유 문체 포인트
- 개조식 서술 불릿도 "…추진할 계획임", "…절대적으로 필요하며 …과제를 추진할 계획임"처럼 전략적 의지로 맺는다([공통원칙 §1]).
- 강조 어휘("선도연구그룹", "원천기술 확보", "고도화", "절대적으로 필요")를 **절제**해 사용.
- 기관 역량에는 정량 실적을 최소 1개씩 넣고, 추가 투자엔 금액·모형을 명시([공통원칙 §3]). 검증은 차년도/단계로 구체화("3~4차년도 실선 모사 실내 모형시험").
- 마커 계층·표/도식·약어 정의는 [공통원칙 §2·§4·§5].

## 대표 예문 (3문서)
- **D1(역량표 셀)**: "ü 100명 이상의 석·박사급 연구원… 자체 개발하여 상용화 중이고… 자율운항·CBM++ 등에 참여" → 역량은 인력규모·자체SW·유사R&D 실적을 셀 안 `ü` 불릿으로.
- **D1(전략 불릿)**: "ㅇ 공동연구기관과 주기적 워크숍·브레인스토밍으로 마일스톤 점검 및 개발기술 수시 평가" → 협력·검증 전략은 `ㅇ` 상위 + `-` 세부로.
- **D3(위험극복 표)**: "실증사이트 확보 방안 | Ÿ 수요기업 추진중 사이트를 우선 실증사이트 지원 가능여부 검토 예정" → 위험요소별 구체 대응책을 `Ÿ` 불릿으로.
- **D11(단계 서술)**: "① LCO2 탱크 설계·해석 기반 구축 — 소재·용접부 특성 평가: …DB 구축 / 소형 시험편 기반 실험·해석: …" → 로드맵을 `①②③`로 쪼개 각 단계 세부활동을 콜론 뒤에.
- **D11(협업체계)**: "각 참여기관 연구개발은 유기적 협업체계로 상호 연계하여 체계적·효율적으로 추진됨" → 협의체 다이어그램으로 데이터 공유·공동 의사결정 표현.

## 체크리스트
- [ ] 모든 참여기관이 역할(주관/공동/수요)과 함께 표에 등장.
- [ ] 기관 역량에 정량 실적(인력/실적/장비/제작능력) 최소 1개씩.
- [ ] 추가 투자계획(금액·모형)이 필요한 기관에 명시.
- [ ] 협력·검증·상용화 전략이 `ㅇ` 불릿으로 서술.
- [ ] 검증계획이 차년도/단계로 정량화.
- [ ] 추진체계/협업체계 개념도 자리 + 캡션 존재.
- [ ] (실증/안전형) 위험극복 방안 표 존재.
