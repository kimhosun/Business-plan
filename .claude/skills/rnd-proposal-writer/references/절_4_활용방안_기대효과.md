# 절 상세: 4장 연구개발성과의 활용방안 및 기대효과

- **적용 절**: 4. 연구개발성과의 활용방안 및 기대효과 (4-1 활용방안 · 4-2 기대효과 · 4-3 기술기여도)
- **대응 스킬**: `rnd-write-4-utilization`
- 공통 문체·서식·정량화·표 규칙은 재서술하지 않음 → `00_공통_작성원칙.md` 참조.

## 표준 골격 (3문서 공통 뼈대)

### 4-1. 활용방안 — 두 묶음
1. **[예상되는 연구개발 주요 성과]** — 산출 핵심 성과물을 성과 단위로 나열(3~5개).
2. **[연구개발 성과의 활용분야 및 활용방안]** — 각 성과의 사용처·방식. 서사 축: **직접 산업현장 적용 → 유사 산업/구조물 확장 → 표준·인증·디지털 연계**.
   - 단골 활용 축(과제 무관 채움 후보): 제작·시공·운항 공정 즉시 적용 / 선급·표준·규격 개정 및 인증(AiP, IGC Code, 가이드라인) / 유사 구조물·타 산업 확장 / 디지털 트윈·실시간 모니터링·CBM 연계 / 실증(목업·실해역) 데이터 후속 활용.

### 4-2. 기대효과 — 세 측면 (완전 공통, 셋 다 필수)
- **[과학⋅기술적 측면]** — 세계 최초/신기술 확보, 메커니즘 규명, 해석·측정 기술 내재화, 표준·규격 선도.
- **[경제적․ 사회적 측면]** — 원가·공기 절감, 수주·시장 선점, 국산화·수입대체, 고용·지역경제, 친환경·탄소저감, 주민수용성.
- **[인프라 측면]** — 테스트베드 구축, DB·디지털 자산화, 전문인력 양성, 검사·인증 시장 창출.
- 각 측면 아래 `ㅇ/◦` 항목 + 하위 `-/—/·` 근거.

### 4-3. 기술기여도 — 표
- 열: `연구개발기관명` + 연차별 `기술기여도(단위: %)`.
- 각 기관 값은 연차 내내 **동일 값 반복** 관행(예: 29.34가 1~7년차 반복). 기관 합은 연차별 100% 정합.

## 문서별 변형 (유형 택1)

| 구분 | D1 (디지털트윈·연구형) | D3 (프리파일링자켓·실증형) | D11 (LCO2탱크·간결형) |
|---|---|---|---|
| 4-1 성과 헤더 | 대괄호 헤더 생략, `ㅇ`로 바로 전개 | `[예상되는…]`/`[활용분야…]` 대괄호 명시(가장 뚜렷) | 성과 유형별 `◦`로 바로 전개 |
| 4-1 밀도 | 중간, 검사·모니터링 서사 | 최다, 정량 목표(10% 이상) 촘촘 | 짧게, 규격 개정·확장 근거 |
| 4-2 마커 | `ㅇ → -` 명사형 종결 | `ㅇ → -` 국산화·수입대체·시장활성화 서사 | `◦ → — → ·` 3단, 반개조식(~확보함/기대됨) |
| 4-3 연차 헤더 | `연구개발종료 N년차` | `연구개발종료 N년차` | `매출액발생 N년차` + `※ 기술료 납부 의무기관만 작성` |

**새 과제 유형 판단 기준**
- 연구형·모니터링/디지털 과제 → **D1** 골격(대괄호 절제, 검사·건전성 서사).
- 실증형·대형 컨소시엄·비용/기간 절감 목표 → **D3** 골격(대괄호 성과 헤더 명시, 정량 목표 조밀, 국산화 서사).
- 공정 대체·짧은 밀도·기술료 납부 기관 → **D11** 골격(◦/—/· 3단, 강한 정량화, 매출액발생 N년차 헤더).
- 밀도 선택은 `[공통원칙 §6]`.

## 절 특유 문체 포인트 (공통과 다른 점만)
- **4-1의 이중 묶음 원칙**: "무엇을 만드는가([주요 성과])"와 "어디에 쓰는가([활용분야·방안])"를 반드시 분리. 한 덩어리로 뭉치지 않는다.
- **4-2의 세 측면 강제**: [과학⋅기술적]/[경제적․ 사회적]/[인프라] 중 하나라도 빠지면 절 미완. 소재는 과제에 맞게 치환하되 세 측면 뼈대는 유지.
- **강조어의 절제된 배치**: "세계 최초·선도·선점·주도권·초격차·블루오션" 등은 4장에서 특히 자주 쓰이지만 **반드시 근거·수치와 동반**. 나열식 남발 금지.
- **활용/효과 항목마다 정량 목표**: `[공통원칙 §3]` 을 4장에서는 항목 단위로 강하게 적용(% / 건 / 명 / 개사 / Ton). 완충어 `약/이상` 동반.
- 종결형·마커 계층은 `[공통원칙 §1][공통원칙 §2]`. 4-3 표 서식은 `[공통원칙 §4]`, 기관명·약어는 `[공통원칙 §5]`.

## 대표 예문 (3문서, 짧게)
- **D1**: `ㅇ 디지털 트윈 기술 기반 장기 선체 구조 건전성 예측 및 관리 / - … 국부 응답을 예측함으로써 … 상시 관리 가능` — 성과는 `ㅇ`, 편익은 `-`, "가능/선도" 명사형 종결로 마무리.
- **D3**: `[예상되는 연구개발 주요 성과] / ㅇ … 설치비용 저감형 지지구조물 개발 / - 경제성 및 기간을 10% 이상 단축 … 신공법 개발` — 성과·활용 묶음을 대괄호로 분리, 각 항목에 "10% 이상" 정량 목표, 국산화·시장활성화 서사.
- **D11**: `◦ 세계 최초 40mm 초과 MSR 공법 확보 및 실증 / — 국제 규격 개정 주도 / · … 세계 최초로 실증하여 확장 근거 확보함` — ◦→—→· 3단, 강조어+수치 동반, "~확보함/기대됨" 반개조식 종결.
