### 6-1. 안전조치 이행계획
머리표 `[연구소/연구실 단위 안전조치 이행계획]`. **참여기관마다** 아래 **6개 소항목**을 `o` 마커로 순서 고정 반복.
1. **o 안전책임자의 지정·운영** — 산업안전보건법 제15조/연구실안전법에 따른 책임자·담당자 지정, 조직체계
2. **o 안전관리규정의 제정·운영** — 내부 규정명·근거법령, 일상/정기 점검 운영
3. **o 안전관리비 계상** — 근거(연구실안전법 시행령 제17조/시행규칙 제13조), **인건비 총액의 1~2%** 계상, 용도(교육·건강검진·보호구·보험·시설유지)
4. **o 안전사고발생시 보고 및 조치** — 보고체계, 중대사고 시 현장보존·조사 절차
5. **o 사고 발생 시 대처방안 및 행동요령** — 최초목격자 조치·응급조치·비상연락·2차사고 방지
6. **o 안전교육 실시 등** — 정기/신규/특별 교육 시간·주기·대상·방법

### 6-2. 보안조치 이행계획 — 표준 보안점검표(핵심)
**참여기관마다** 머리표 `ㅇ 주관연구개발기관 : <기관명>` / `ㅇ 공동연구개발기관 : <기관명>` 후, **정부 표준 보안점검 체크표** `구분 | 체크항목 | 결과 체크(√표) | 비고(미실시 사유)` 4열. **5개 구분(고정)**:
1. **보안관리체계** — 보안관리규정 제정/적용(*규정명칭*) / 보안조직·자체점검(*담당부서·성명·점검일자*) / 보안교육 연1회 이상(*실시일자*) / 보안사고 방지대책·비상대응계획(*조문·가이드*)
2. **참여연구자 관리** — 보안서약서·보안교육 / 해외출장 사전교육·귀국보고 / 퇴직예정자 서약서·자료회수·전산망 차단 / 외국인 영문서약서·출입제한(미참여 시 공란)
3. **연구개발 내용/결과 관리** — 무단유출 방지대책 / 보안성 검토 절차 / 기술이전 내부규정 준수
4. **연구시설 관리** — 출입권한 차등 / 보안장비·보호구역 지정 / 외부 입주기관 출입통제(없으면 공란)
5. **정보통신망 관리** — 내부규정 / 보안책임자 승인항목 구분 / 데이터 백업 / 개인장비(노트북·USB) 인가·관리 / 전산망 보호 HW·SW / 직책·임무별 열람권한 차등

각 체크항목 끝에 `O( √ ), X(   )` 표기. **미해당 항목(외국인 미참여·외부 입주기관 없음)은 체크 공란 + 비고에 사유** [공통원칙 §4]. 빈 체크 남발 금지 — `O( √ )`에는 **구체 근거(규정명·담당자·일자)** 부기.

### 6-3. 그 밖의 조치사항 이행계획 (선택 — 현장/실증형)
머리표 `[연구개발과제 단위의 안전관리 방안]`. 과제 고유 기술위험을 `o`(또는 `□`)로:
- **o 국내·외 안전사고 사례** — 사례명(발생국) + `·`근본원인. 필요 시 사진/개요/원인/개선방향 표.
- **o 안전기준 준수 방안** — 책임자 선정·매뉴얼·모의훈련·법령준수
- **o 위험성 사전 검토·예측 결과** — 장비/작업별 매뉴얼, 위험요소별 중점 실시사항 표
- **o 수행 중·종료 후 안전점검(일상·정기·특별)·정밀안전진단 계획** — 위험성평가 5단계, 안전작업계획서, KOSHA GUIDE·법정기준 인용
