## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§3 정량화·근거 표기** — 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.
- **§6 분량·밀도 선택** — 밀도 스펙트럼: **D1 장문 ~ D3 상세 ~ D11 단문**. 과제 규모·유형(연구형/실증형)·참여기관 수에 맞춰 택한다.
- **§7 절 간 정합성 (전체 작성 시 필수)** — **목표 사슬**: 2-1 정량 성능지표 = 2-2 각 차년도 목표 = 2-3 일정·주요 결과물.
- **§8 금지사항** — 특정 참조문서의 문장을 **그대로 베끼기**(주제·문구는 새로 작성).

## 골격 지침
- 위에서부터 순서대로. 참여기관 수만큼 7-1(2)와 참여연구자 행이 반복.
- 7-1. 연구책임자 및 참여연구자 등 현황
- **(1) 주관연구개발기관책임자(연구책임자)** — 소항목 가~사를 표로:  · **가. 인적사항**: 국·영문 성명 / 국적 / 국가연구자번호 / 기관·부서·직위 / 전화·휴대·전자우편 / 주소(우편번호)  · **나. 학력**: 취득연월 / 학교 / 전공 / 학위 / 지도교수 (최근순) + 최종학위 논문명  · **다. 경력**: 기간 / 기관 / 직위 / 비고 (최근순, "~현재")  · **라. 국가연구개발 실적 및 현황**: 중앙행정기관(전문기관) / 세부사업 / 과제명 / 주관기관 / 전체기간(참여기간) / 역할(책임자·연구자) / 비고(신청·수행중·완료) / 당시 소속  · **마. 대표 논문·저서 실적**: 구분 / 논문·저서명 / 게재지(권,쪽) / 게재연도 / 역할 / ISSN / 비고(피인용·IF)  · **바. 지식재산권 출원·등록 실적**: 구분(특허/프로그램) / 명칭 / 국가 / 출원·등록일 / 번호·등록자수 / 비고(출원/등록)  · **사. 그 밖의 수상경력 등 대표 실적**: 구분 / 실적명 / 내용요약 / 실적연도
- **(2) 공동연구개발기관책임자** — `[공동연구개발기관N – 기관명]` 또는 `(2-1) 기관명` 헤딩 아래 가~사 골격 **동일 반복**. (D3는 `[수요기업N – 기관명]`도 별도)
- **(3) 참여연구자 및 연구지원인력**  · **가. 참여연구자 현황**(대형 표): 번호 / 소속기관(역할) / 신규구분(청년의무·추가·기타)·기존·시간선택·외부 / 성명(국적) / 직위 / 생년월일(성별) / 학위·전공·취득년도 / 담당역할 / 참여기간 / 본과제 인건비계상률(A) / 타 국가R&D 계상률(B) / 합계(A+B) / 참여과제수(3책/5공)  · **나. 연구지원인력 현황**  · **다. 여성 참여연구자 비율**: 총원 / 여성수 / 비율(%)  · **라. 연구개발기관이 아닌 관계 기관** (없으면 "- 해당없음")
- 7-2. 연구시설·장비 보유현황
- ※ 안내: "ZEUS 등록번호 있으면 ZEUS번호, 없으면 자산등록번호 기재"
- 표 열: 보유기관 / 시설·장비명(ZEUS·자산번호) / 구매일자 / 구매금액(천원) / 활용시기 / (내용연수) / 연구개발 중 사용용도 / 현물부담 반영("○") / 현물부담금액(천원)
- 기관별로 묶어 나열. 상용 SW(ABAQUS·ANSYS·NASTRAN·Matlab 등)·서버/클러스터·시험장비(만능재료·피로·충격시험기 등)를 사용용도와 함께.
- 7-3. 연구개발기관 일반 현황
- **(1) 일반 현황**  · **ㅇ 비영리기관**: 사업자·법인등록번호 / 대표자(성명·국적) / 기관유형 / 지원담당자(성명·부서·직위·전화·전자우편·팩스)  · **ㅇ 기업**(단위 천원·%): 사업자·법인등록번호 / 대표자 / 기업유형(중소·중견·대기업) / 최대주주 / 설립연월일 / 주생산품목 / 상시종업원수 / 직전년도 매출 / 매출 대비 R&D비율 / **재무분석 3개년**(부채비율·유동비율·자본총계·자본금·영업이익·이자보상비율)
- **(2) 국가R&D·기술이전·사업화·보유특허 실적** *(D1·D11 수록, D3 생략 가능)*  · **o 국가R&D 주요 수행실적**: 기관명 / 과제명 / 주관기관 / 기간(참여기간) / 개발내용(핵심 요약) / 중앙행정기관(전문기관) / 비고(수행중·완료) / 역할(주관·공동)  · **o 동 과제 관련 기보유 지재권 출원·등록 현황**: 소유권자 / 명칭 / 국가 / 출원·등록번호·일  · **o 기술이전 실적 / o 사업화 실적** (없으면 표 골격 + 각주 `1」2」3」`만 유지)

## 문서별 변형 지침
- 유형 · 대표문서 · 구성·밀도 · 언제 고르나
- **소규모·표준형** · D1(디지털트윈)·D11(LCO2) · 3~4기관, 책임자별 가~사 1p 내외. 7-3(2) **국가R&D·특허 실적 수록** · 연구형·중소 컨소시엄. 논문·특허 경쟁력을 정량 지표로 부각
- **대형 컨소시엄형** · D3(프리파일링 자켓, 12기관·109명) · 참여연구자 표·시설장비 수십 행. **현물부담·사업화 실적** 적극 기재. 수요기업 책임자 별도 · 실증형·대형 컨소시엄. 현물 출자·실증 물자·사업화 트랙레코드가 있을 때
- 밀도 스펙트럼은 [공통원칙 §6]. 참여기관·인원 수에 비례해 택한다.
- **7-3(2) 실적표**: 논문·특허 실적이 강하면 D1/D11형으로 수록, 실증·설치 실적 중심이면 D3형으로 사업화·현물에 무게.

- **정량 표기 세부**: 금액 천원, 기간 `YY.MM~YY.MM` 또는 `YYYY.MM.DD`, 논문은 게재지·권·쪽·ISSN·(선택)IF·피인용·FWCI. (일반 정량 규칙 [공통원칙 §3])
- **계층 마커 이 장 관행**: 대분류 `ㅇ`/`◦`, 실적 소분류 `o`, 인적사항 하위 `가.·나.·다.`, 절 `(1)(2)(3)`, 안내문 `※`, 각주 `1」 2」`.
