## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§2 마커·번호 계층** — 계층 순서: `□ 또는 [대괄호 머리말] → ㅇ(◦) → -(—) → ·`.
- **§3 정량화·근거 표기** — 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.
- **§4 표 서식 관행** — 상당수 절은 자유 서술이 아니라 **정형 표 채우기**다. 표의 열·행 구성과 코드·관계식(예: 예산 K=직접비, M=K+L)을 유지한다.
- **§5 용어·기관명** — 영문 약어는 **최초 등장 시 정의**(예: PWHT, BIM, MSR, IEC, IACS, TRL/CRL).
- **§6 분량·밀도 선택** — 밀도 스펙트럼: **D1 장문 ~ D3 상세 ~ D11 단문**. 과제 규모·유형(연구형/실증형)·참여기관 수에 맞춰 택한다.
- **§7 절 간 정합성 (전체 작성 시 필수)** — **목표 사슬**: 2-1 정량 성능지표 = 2-2 각 차년도 목표 = 2-3 일정·주요 결과물.
- **§8 금지사항** — 특정 참조문서의 문장을 **그대로 베끼기**(주제·문구는 새로 작성).

## 골격 지침
- 순서대로 채운다.
- **(1) 최종목표**  · 최종목표를 **1문장 명사형**으로 압축(대상·공법·정량지표·검증방식 포함). 필요 시 개념도 자리.  · 이어 **세부목표/개발내용 분해**: 번호목록(D1) / `RFP개발목표 ↔ 본 연구 개발내용` 2열표(D3) / `구분|연구개발기관|최종목표 및 수행내용` 3열표(D11).  · (있으면) `[1단계(YYYY~YYYY) 목표]` 아래 `세부목표 1·2·3…` + `☞ 달성수준`(D1 방식).
- **< 연구개발성과 성능 목표 >** 표 — 열: `평가항목(주요성능 Spec¹⁾) | 단위 | 비중²⁾(%) | 세계최고 수준 보유국/보유기업 | 개발 전 국내수준 | 개발 목표치(단계·차년도별) | 표준(시험)·인증기준³⁾ | 기준설정 근거⁴⁾ | 평가 방법⁵⁾`. 비중 합계 100, 목표치는 **단계×차년도 칸마다** 수치. (각주번호 유지 → [공통원칙 §4])
- **< 기술개발 핵심어 >** : 한글 5개 / 영문 5개, 1:1 대응.
- **< 연구개발성과의 지표 및 목표 >** : 논문·특허·보고서원문·SW(전담기관 등록·기탁) + **과제특성 반영 지표**를 단계별 목표건수 + 가중치(%)로. 가중치 합 100.
- **(2) 정량적 목표 항목의 평가방법 및 평가환경** 표 — 열: `순번 | 평가항목(성능지표) | 구분(단계-차년도) | 평가방법 | 평가환경`. `평가방법`=평가주체(수요기업·제3자기관/자체평가(3자 입회)/자체시험), `평가환경`=정량 근거(`-`로 시작하는 개조식).
- **(3) 보안등급의 분류 및 해당 사유** — `보안과제( ) 일반과제(√)` + 결정 근거·사유, 그리고 **5개 심사기준 표**(방위력개선사업/국산화 미래핵심기술/미래핵심기술/국가핵심기술/수출허가 제한 기술) 각 `예/아니오` 체크.

## 문서별 변형 지침
- **D1 (2단계×2차, 지표 5개)**: (1)에 최종목표 1문장 + 번호목록 + `[1·2단계] 세부목표 n ☞ 달성수준`. 보안등급표 뒤에 **특성반영지표 평가표**를 한 번 더.
- **D3 (2단계×3차, 지표 최다·22개까지)**: (1)을 `순|RFP개발 목표|본 연구 개발내용` 2열표. 성능표에 **TRL/CRL(1~9) 행**을 최상단, `수행기관` 열 포함. (2)를 **① 정량적 기술 목표 / ② 정량적 성과 목표**로 이분, `< 정량적 성과 목표 >` 표(사업화·매출·고용·특허·논문) 별도.
- **D11 (1단계×4차, 간결)**: (1)을 `구분|연구개발기관|최종목표 및 수행내용` 3열 기관 매트릭스. (2)에 성과지표(논문·특허·고용)까지 한 표로 통합.
- **선택 기준**: 단계 구성(2단2차→D1 / 2단3차·대형 컨소시엄→D3 / 1단4차·간결→D11)과 지표 수로 밀도 택1. [공통원칙 §6]

## 문체·표기 지침
- 목표치는 반드시 **"개발 전 국내수준 → 단계·차년도별"** 상승 곡선으로 (예: 오차율 `50→30→20(%)`, 정확도 `70→75→80→85(%)`, TRL `4→5→6→7`).
- **모든 성능지표에 단위·목표치·평가방법을 빠짐없이** 붙인다. 목표엔 완충어 `이상/이내` 동반. [공통원칙 §3]
- 세계최고수준은 `보유국/보유기업` 실명(예: 노르웨이/DNV, 덴마크/Ørsted). 미상이면 형식만 유지, 허위 실명 금지. [공통원칙 §8]
- 평가환경은 반드시 **정량 근거** 명시("오차율 10% 이내 비교 보고서" 등).
- 달성수준 지시엔 `☞` 마커 사용.

## 체크리스트

- [ ] `< 성능 목표 >` 표: 비중(%) 합 100, 모든 지표에 단위·단계별 목표치·평가방법
- [ ] 목표치가 `개발 전 국내수준 → 단계·차년도별`로 상승
- [ ] 핵심어 국·영문 각 5개 1:1
- [ ] `< 지표 및 목표 >` 가중치(%) 합 100, 과제특성 반영 지표 포함
- [ ] (2) 평가방법(주체)/평가환경(정량 근거)이 모든 성능지표에 대응
- [ ] (3) 보안등급 분류 + 5개 심사기준 체크 + 사유
- [ ] 지표·수치가 2-2·2-3과 정합 [공통원칙 §7]
