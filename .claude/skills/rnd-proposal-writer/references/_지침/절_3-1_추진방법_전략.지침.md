# [지침] 절 3-1. 기술개발 추진방법·전략

> 원본: `절_3-1_추진방법_전략.md` · 대응 스킬: `rnd-write-3-1-strategy` · 적용 절: 3-1. 기술개발 추진방법·전략

## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§2 마커·번호 계층** — 계층 순서: `□ 또는 [대괄호 머리말] → ㅇ(◦) → -(—) → ·`.
- **§3 정량화·근거 표기** — 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.

## 골격 지침
- **(1) 참여기관 역량 / 기술개발 방법** — 아래 두 형태 중 과제 성격에 맞게 택1  · **형태 A(기관 역량 중심)**: `기관명 | 역할(주관/공동/수요) | 기관 역량·실적·추가 투자계획` 3열 표. 셀 안은 `ü`/`·` 불릿 2~4개.  · **형태 B(개발 방법·흐름 중심)**: 개발 단계·주체를 열로 둔 개념표(예: `사업자 | 신공법·설계 | 검증 | 실증·사업화 | 수요기업`) 또는 로드맵 그림 + `①②③` 단계 서술.
- **추진방법·전략 서술** — 표 아래 `ㅇ` 개조식 불릿 6~10개(협력체계·정량지표 사전협의·수요기업 우선검증·차년도 검증계획·상용화·필요시 위탁).
- **협업체계/추진체계 개념도** — 순환·수렴 구조 다이어그램 1개(그림 자리 + 캡션).
- **(선택) 위험극복 방안** — `위험요소 | 위험극복 방법` 2열 표. 실증·안전관리형에서 권장.

## 문서별 변형 지침
- **D1(연구형·형태 A)**: (1) 참여기관 역량 표 → (2) 추진방법·전략(개념도 + `ㅇ` 불릿 다수). 인력·자체SW·유사R&D 실적 중심.
- **D3(실증형·형태 B)**: (1) 기술개발 방법(단계·주체 흐름표 + `ㅇ` 불릿) → (2) **위험극복 방안 표**가 두드러짐(실증·안전관리형).
- **D11(간결형·로드맵)**: 연구개발 로드맵 그림 + `①②③` 단계 서술 → 기관별 역량표 + 협의체(LCO2 MSR) 협업 다이어그램.
- **판단 기준**: 실증·시공형이면 형태 B + 위험극복 표. 연구·SW형이면 형태 A. 단계가 명확한 요소기술 축적형이면 D11식 로드맵.

## 문체·표기 지침
- 개조식 서술 불릿도 "…추진할 계획임", "…절대적으로 필요하며 …과제를 추진할 계획임"처럼 전략적 의지로 맺는다([공통원칙 §1]).
- 강조 어휘("선도연구그룹", "원천기술 확보", "고도화", "절대적으로 필요")를 **절제**해 사용.
- 기관 역량에는 정량 실적을 최소 1개씩 넣고, 추가 투자엔 금액·모형을 명시([공통원칙 §3]). 검증은 차년도/단계로 구체화("3~4차년도 실선 모사 실내 모형시험").
- 마커 계층·표/도식·약어 정의는 [공통원칙 §2·§4·§5].

## 체크리스트
- [ ] 모든 참여기관이 역할(주관/공동/수요)과 함께 표에 등장.
- [ ] 기관 역량에 정량 실적(인력/실적/장비/제작능력) 최소 1개씩.
- [ ] 추가 투자계획(금액·모형)이 필요한 기관에 명시.
- [ ] 협력·검증·상용화 전략이 `ㅇ` 불릿으로 서술.
- [ ] 검증계획이 차년도/단계로 정량화.
- [ ] 추진체계/협업체계 개념도 자리 + 캡션 존재.
- [ ] (실증/안전형) 위험극복 방안 표 존재.
