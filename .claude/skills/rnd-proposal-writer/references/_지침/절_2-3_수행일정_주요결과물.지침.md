# [지침] 절 2-3. 연구개발과제 수행일정 및 주요 결과물

## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§4 표 서식 관행** — 상당수 절은 자유 서술이 아니라 **정형 표 채우기**다. 표의 열·행 구성과 코드·관계식(예: 예산 K=직접비, M=K+L)을 유지한다.
- **§5 용어·기관명** — 영문 약어는 **최초 등장 시 정의**(예: PWHT, BIM, MSR, IEC, IACS, TRL/CRL).
- **§6 분량·밀도 선택** — 밀도 스펙트럼: **D1 장문 ~ D3 상세 ~ D11 단문**. 과제 규모·유형(연구형/실증형)·참여기관 수에 맞춰 택한다.
- **§7 절 간 정합성 (전체 작성 시 필수)** — **목표 사슬**: 2-1 정량 성능지표 = 2-2 각 차년도 목표 = 2-3 일정·주요 결과물.

## 골격 지침
- 두 층위의 표를 조합.
- **추진 일정 요약표(단계·차년도 간트)** — 기관별 또는 전체 통합  · 열: `일련번호 | 개발 내용 | 추진 일정(1단계[1·2·(3)차] / 2단계[1·2·(3)차])` (+ 문서별 `달성도(%)` 또는 `수행기관` 열)  · 각 개발내용 행의 해당 차년도 칸을 막대(음영)로. **개발내용 = 2-2의 대항목**.
- **차년도별 상세 일정표(주 단위 간트)** — 각 (단계-차년도)마다 별도 표  · 헤더: `일련번호 | 개발 내용 | {단계}-{n}차년도({개월}개월) | 기간[주] | 1 2 … {주수}`  · 행마다 개발내용 + `기간[주]` 값. 개월수(9/12/6)에 맞춰 주 칸 수 결정.
- **(있으면) 주요 결과물** — 개발내용별 산출물(보고서·SW·시제품·인증서·지침서)을 연차에 귀속. D3형은 `당초계획/개발실적` 대비 프레임.

## 문서별 변형 지침
- **D1 — 기관별 2층 표 (2단계×2차)**: `[한국선급]`, `[인하대학교]`… 기관마다 ① 단계·차년도 요약 간트 + ② 각 차년도(9/12개월) 주별 상세표. 개발내용은 2-2의 `o 대항목` 그대로.
- **D3 — 기관별 + 달성도 (2단계×3차)**: `### [케이베츠]`… 기관별 파일, 요약 간트에 **`달성도(%)` 열** 추가. 차년도 개월 불규칙(9·9·6·6·12·6) → 각 표 주 칸 수를 개월에 맞춤. 상단 `당초계획/개발실적` 프레임.
- **D11 — 전체 통합 주요일정 + 상세 (1단계×4차)**: `연차단계별 주요일정` 하나의 큰 표에 **전 기관 개발내용 × 담당기관 × 1·2·3·4차** 통합 배치(행 끝 `[기관명]` 병기). 이어 `연차별 상세일정` 세분.
- **선택 기준**: 참여기관 수·단계 구성에 맞게 — 기관별 2층(D1) / 기관별+달성도(D3) / 전체 통합(D11). [공통원칙 §6]

## 문체·표기 지침
- 개발내용 셀은 **명사구**로만("프리석션 설치용 그립퍼 개념 설계", "MSR 공법 인증 및 지침서 개발"). 종결어미·서술문 금지. [공통원칙 §1]
- 머리표: 기관별 표는 `[기관명]`(D1)·`### [기관명]`(D3), 통합표는 행 끝 `[기관명]`.
- **개월/주 정합**: 9개월≈36주, 12개월≈48주, 6개월≈24주. 각 개발내용 `기간[주]`는 해당 차년도 총주수 이내 구간값(누적/구간 중 하나로 일관되게).
- 실제 막대(음영)는 서식에서 채우므로, 텍스트로는 **개발내용 + 기간[주] 값**이 핵심.

## 정합 지침
- **개발내용 = 2-2 대항목** (누락·추가 없음).
- **주요 결과물 = 2-2 산출물 = 2-1 성과지표**. 예: 2-1 "장기 피로손상도 추정 프로그램 1건" ↔ 2-2 "…예측 기술 개발" ↔ 2-3 해당 차년도 일정·결과물. 3절이 하나의 논리로 맞물리게.
- **단계·차년도·개월수는 2-1/2-2와 동일**.

## 체크리스트
- [ ] 추진 일정 요약 간트표(개발내용 × 단계·차년도) + 차년도별 주(週)단위 상세표
- [ ] 배치 단위(D1 기관별 / D3 기관별+달성도 / D11 통합) 일관
- [ ] **개발내용 = 2-2 대항목** (누락·추가 없음)
- [ ] **주요 결과물 = 2-2 산출물 = 2-1 성과지표** 정합
- [ ] 단계·차년도·개월수가 2-1/2-2와 동일, 주 칸 수(9≈36·12≈48·6≈24주) 일치
- [ ] 담당기관 정식 명칭, 약어 정의 유지 [공통원칙 §5]
- [ ] 개발내용 셀 명사구, 서술문 없음
