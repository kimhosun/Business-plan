## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§2 마커·번호 계층** — 계층 순서: `□ 또는 [대괄호 머리말] → ㅇ(◦) → -(—) → ·`.
- **§3 정량화·근거 표기** — 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.
- **§4 표 서식 관행** — 상당수 절은 자유 서술이 아니라 **정형 표 채우기**다. 표의 열·행 구성과 코드·관계식(예: 예산 K=직접비, M=K+L)을 유지한다.
- **§5 용어·기관명** — 영문 약어는 **최초 등장 시 정의**(예: PWHT, BIM, MSR, IEC, IACS, TRL/CRL).
- **§6 분량·밀도 선택** — 밀도 스펙트럼: **D1 장문 ~ D3 상세 ~ D11 단문**. 과제 규모·유형(연구형/실증형)·참여기관 수에 맞춰 택한다.
- **§7 절 간 정합성 (전체 작성 시 필수)** — **목표 사슬**: 2-1 정량 성능지표 = 2-2 각 차년도 목표 = 2-3 일정·주요 결과물.

## 골격 지침
- 4-1. 활용방안 — 두 묶음
- **[예상되는 연구개발 주요 성과]** — 산출 핵심 성과물을 성과 단위로 나열(3~5개).
- **[연구개발 성과의 활용분야 및 활용방안]** — 각 성과의 사용처·방식. 서사 축: **직접 산업현장 적용 → 유사 산업/구조물 확장 → 표준·인증·디지털 연계**.  · 단골 활용 축(과제 무관 채움 후보): 제작·시공·운항 공정 즉시 적용 / 선급·표준·규격 개정 및 인증(AiP, IGC Code, 가이드라인) / 유사 구조물·타 산업 확장 / 디지털 트윈·실시간 모니터링·CBM 연계 / 실증(목업·실해역) 데이터 후속 활용.
- 4-2. 기대효과 — 세 측면 (완전 공통, 셋 다 필수)
- **[과학⋅기술적 측면]** — 세계 최초/신기술 확보, 메커니즘 규명, 해석·측정 기술 내재화, 표준·규격 선도.
- **[경제적․ 사회적 측면]** — 원가·공기 절감, 수주·시장 선점, 국산화·수입대체, 고용·지역경제, 친환경·탄소저감, 주민수용성.
- **[인프라 측면]** — 테스트베드 구축, DB·디지털 자산화, 전문인력 양성, 검사·인증 시장 창출.
- 각 측면 아래 `ㅇ/◦` 항목 + 하위 `-/—/·` 근거.
- 4-3. 기술기여도 — 표
- 열: `연구개발기관명` + 연차별 `기술기여도(단위: %)`.
- 각 기관 값은 연차 내내 **동일 값 반복** 관행(예: 29.34가 1~7년차 반복). 기관 합은 연차별 100% 정합.

## 문서별 변형 지침
- 구분 · D1 (디지털트윈·연구형) · D3 (프리파일링자켓·실증형) · D11 (LCO2탱크·간결형)
- 4-1 성과 헤더 · 대괄호 헤더 생략, `ㅇ`로 바로 전개 · `[예상되는…]`/`[활용분야…]` 대괄호 명시(가장 뚜렷) · 성과 유형별 `◦`로 바로 전개
- 4-1 밀도 · 중간, 검사·모니터링 서사 · 최다, 정량 목표(10% 이상) 촘촘 · 짧게, 규격 개정·확장 근거
- 4-2 마커 · `ㅇ → -` 명사형 종결 · `ㅇ → -` 국산화·수입대체·시장활성화 서사 · `◦ → — → ·` 3단, 반개조식(~확보함/기대됨)
- 4-3 연차 헤더 · `연구개발종료 N년차` · `연구개발종료 N년차` · `매출액발생 N년차` + `※ 기술료 납부 의무기관만 작성`
- **새 과제 유형 판단 기준**
- 연구형·모니터링/디지털 과제 → **D1** 골격(대괄호 절제, 검사·건전성 서사).
- 실증형·대형 컨소시엄·비용/기간 절감 목표 → **D3** 골격(대괄호 성과 헤더 명시, 정량 목표 조밀, 국산화 서사).
- 공정 대체·짧은 밀도·기술료 납부 기관 → **D11** 골격(◦/—/· 3단, 강한 정량화, 매출액발생 N년차 헤더).
- 밀도 선택은 `[공통원칙 §6]`.

- 종결형·마커 계층은 `[공통원칙 §1][공통원칙 §2]`. 4-3 표 서식은 `[공통원칙 §4]`, 기관명·약어는 `[공통원칙 §5]`.
