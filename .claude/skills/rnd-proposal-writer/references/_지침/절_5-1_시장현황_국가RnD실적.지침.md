## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§3 정량화·근거 표기** — 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.
- **§4 표 서식 관행** — 상당수 절은 자유 서술이 아니라 **정형 표 채우기**다. 표의 열·행 구성과 코드·관계식(예: 예산 K=직접비, M=K+L)을 유지한다.

## 골격 지침
- A형 — 시장현황형 (D1·D11)
- (도입) 대상 기술 개념·성장배경·성숙단계·세계 수준 요약 (D1은 (1)(2) 앞에 크게 배치)
- (1) 국내 기술 수준 및 시장 동향  · `[국내 기술 동향 및 수준]` — 분야·기업별 적용 사례 나열  · `[국내시장 규모 및 수출·입 현황]` — 규모 수치, 수요 예측, (D11) HS코드 수출입 통계
- (2) 국외 기술 수준 및 시장 동향  · `[국외 기술 동향 및 수준]` — 해외 기업·프로젝트 사례  · `[국외시장 규모 현황]` — 글로벌 규모·전망(연도·달러·CAGR)
- B형 — 실적형 (D3)
- 표 4종을 순서대로. 단위를 헤더에 명시.
- `o 국가연구개발사업 주요 수행실적` — 열: 기관명 / 과제명 / 주관기관 / 기간 / 개발내용요약 / 총연구개발비(백만원) / 중앙행정기관(전문기관) / 비고(수행중·완료) / 역할(주관·공동)
- `o 기보유 지재권 출원·등록 현황` — 열: 기관명(소유권자) / 지재권명 / 국가 / 출원·등록번호·일
- `o 기술이전 실적`(천원) — 열: 기관명 / 이전유형(통상실시권 등) / 계약명 / 실시기관 / 발생일 / 기술료 / 누적징수액
- `o 사업화 실적`(천원) — 열: 기관명 / 방식 / 형태 / 지역 / 사업화명 / 내용 / 업체명 / 매출액 / 매출연도 / 기술수명

## 문서별 변형 지침
- **A형(D1·D11)**: 신기술의 시장 자체를 설득. 도입 서술이 두껍고 국내→국외 각각 "기술 동향+시장 규모" 2축. D1은 도입부를 크게, D11은 수치 사슬(감축량→저장능력→필요량)로 필요성 유도.
- **B형(D3)**: 다수 기업 컨소시엄으로 기보유 특허·기술이전 이력이 많을 때. 서술 대신 표 4종.
- **판단**: 참여기업 다수+실적 풍부 → B형. 신시장 설득 필요 → A형. RFP 목차 우선. **A·B 혼용 금지.**

## 문체·표기 지침
- 적용 사례는 `(기관/기업명) …을 개발/추진/시도함` 한 줄씩, 국내→국외·분야별로 묶음.
- 시장 규모는 항상 "연도+달러(또는 원)+CAGR%"+출처 병기 (`[공통원칙 §3]`).
- 표는 줄 단위 평탄화 추출이어도 무방하나, 사용자에겐 정식 표로 정리 제안 (`[공통원칙 §4]`, `§8` 잡음 구분).
- 개조식 명사형 종결·마커 계층은 `[공통원칙 §1, §2]`.

## 체크리스트

- [ ] (A) 국내·국외 각각 "기술 동향"+"시장 규모" 2축이 있는가.
- [ ] (A) 모든 시장 수치에 연도·단위·출처가 붙었는가.
- [ ] (B) 표 4종이 모두 있고 열 누락·단위(백만원/천원) 불일치가 없는가.
- [ ] 개조식 종결·마커 계층 준수 (`[공통원칙 §1, §2]`).
