## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§2 마커·번호 계층** — 계층 순서: `□ 또는 [대괄호 머리말] → ㅇ(◦) → -(—) → ·`.
- **§3 정량화·근거 표기** — 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.
- **§4 표 서식 관행** — 상당수 절은 자유 서술이 아니라 **정형 표 채우기**다. 표의 열·행 구성과 코드·관계식(예: 예산 K=직접비, M=K+L)을 유지한다.
- **§5 용어·기관명** — 영문 약어는 **최초 등장 시 정의**(예: PWHT, BIM, MSR, IEC, IACS, TRL/CRL).
- **§6 분량·밀도 선택** — 밀도 스펙트럼: **D1 장문 ~ D3 상세 ~ D11 단문**. 과제 규모·유형(연구형/실증형)·참여기관 수에 맞춰 택한다.
- **§7 절 간 정합성 (전체 작성 시 필수)** — **목표 사슬**: 2-1 정량 성능지표 = 2-2 각 차년도 목표 = 2-3 일정·주요 결과물.
- **§8 금지사항** — 특정 참조문서의 문장을 **그대로 베끼기**(주제·문구는 새로 작성).

## 골격 지침
- 이 장은 **거의 전부 표(表)** 다. 실제 "문체"는 ① 표의 열·행 구성, ② 셀 안 개조식 명사구(사용용도·산정사유), ③ 표 하단 각주·※ 규정문 세 가지뿐 → [공통원칙 §4].
- **8-1. 지원·부담계획** — 단계 × 연차 × 기관 매트릭스, 소계·총계.
- **8-2. 사용계획**  · (1) 총괄표 — 비목별 전체 합산.  · (2) 기관별 사용계획 — 기관마다 [총괄표 + 각주 1)~4) + 참여연구자 인건비 현황표 (+ 학생인건비 현황표)].
- **8-3. 세부 사용계획** — (1) 장비 구축(임차)/(1-1)(1-2) 운영·활용, (2) 연구재료 구입비/(2-1) 재료제작비, (3) 외주 용역비/(3-1) 연구활동비 세세목, (4) 간접비.
- D11(액화 CO2)에는 8장이 **없다**. 이 절은 **D1·D3 두 문서**만 근거.

## 문서별 변형 지침
- 항목 · D1형(연구형·중밀도) · D3형(실증형·대형 컨소시엄)
- 단계·연차 · 1·2단계 각 2차년도 → **총괄표 4개 연도열** · 1·2단계 각 3차년도 → **총괄표 6개 연도열**
- 8-1 '그 외 기관 지원금' 열 · **없음** · **있음**(수요기업·지자체 참여)
- 8-1 합계 코드 · 합계=A+D · 합계=**(H)**, 비율 분모도 H
- 8-2(2) 기준 차수 · **2단계-1차년도** 기준 · **1차년도** 기준
- 8-3 재료제작비/외주 · (2-1) 없음, 외주 소규모(2건) · (2-1)·(3) 대형(강재구매·구조물제작·해외인증)
- **유형 선택**: 수요기업·지자체가 예산을 분담하거나 대형 실증 물량이 있으면 **D3형**, 순수 연구·소규모 컨소시엄이면 **D1형** → [공통원칙 §6].

## 문체·표기 지침
- 이 장은 **산문을 새로 쓰지 않는다** — 소절 제목 + 표 + 각주/※ 만. 표 사이 해설 문단 삽입 금지.
- 셀 안 사용용도·산정사유 = 개조식 명사구(예 "센서 신뢰성 검증", "해상실증용 해저기초구조물") → [공통원칙 §1].
- 모든 금액표 첫 줄 `(단위 : 천원)`, 천단위 콤마 정수 → [공통원칙 §3].
- 회계연도 범위 표기: `'26.1~12`, `'26.7~12`, `'26.1~'26.6`.
- 비목 표준용어·각주 정의문·※ 규정 인용문은 표준 문구이므로 **재사용 허용**(주제·기관명·금액만 새로 산정).

## 비목·코드 관계식
- 8-1 열 골격
- `구분(단계/연차/기관/기업유형) | 정부지원 현금(A) | 기관부담[현금(B)/현물(C)/소계(D)] | (D3만) 그 외 지원금[현금(E)/현물(F)/소계(G)] | 합계 | 비율(A/합계, B/D, C/D, D/합계)`
- 각 단계 끝 **소계**, 문서 끝 **총계** 행. 기업유형: 중소기업/대기업/대학/출연연/공기업/기타.
- 8-2(1) 총괄표 비목 세로축(고정 순서) — 코드 유지 [공통원칙 §4]
- 직접비
- 인건비: 내부(A) 현금/현물, 외부(B), 연구지원인력(C), 학생(D)
- 총 인건비 E1 = A+B+C+D,  인건비 비율 E1/M
- 연구시설·장비비(F) 현금/현물
- 연구재료비(G) 현금/현물
- 연구활동비(H) 현금/현물
- 연구수당(I) / 보안수당(S) / 국제공동연구개발비(T)
- 직접비 소계 K = E1+F+G+H+I+S+T
- 간접비(L)
- 연구개발비 총액 M = K+L
- 가로축 = 단계·차년도별 + 합계(연도 서기 병기).
- 8-2(2) 기관별 총괄표 추가 코드·각주
- 위 구조에 (N)(O)(P)(Q)(R) 코드 + **수정인건비 E2 = A+B+D** 행, 연구수당 비율(I/E2)·간접비 비율(L/수정직접비) 행 포함.
- **각주 1)~4)는 고정 문구**(그대로 재사용, [공통원칙 §8]의 "베끼기 금지" 예외 — 표준 정의문):
- 1) 총 인건비 = 내부+외부+연구지원인력+학생 인건비
- 2) 수정인건비 = 내부+외부+학생 인건비
- 3) 연구수당 비율 = (연구수당/수정인건비)×100
- 4) 간접비 비율 = (간접비/수정직접비)×100, *수정직접비 = 직접비 소계 − 직접비(현물) − 국제공동연구개발비
- 인건비만 현물 계상하는 기업(예: 대기업)은 내부인건비 **현물** 행만, 연구수당·간접비는 0.
- 8-3 세세목 명명 규칙
- (3-1)·(4) 명칭은 반드시 `표기명(공식 세세목)` 형식: `회의비(회의비)`, `전문가활용비(외부전문기술 활용비)`, `사무용품비(연구실 운영비)`, `학회 및 세미나 참가비(연구인력 지원비)`, `논문 게재료(그 밖의 비용)`; 간접비는 `연구지원비(연구실 안전관리비)`, `성과활용지원비(지식재산권 출원 및 등록)` 등.

## 체크리스트
- [ ] **8-1 총계 = 8-2(1) 총액(M) = 8-2(2) 각 기관 총액 합** (3표 일치).
- [ ] 8-3 (1)장비·(2)재료·(2-1)제작·(3)(3-1)활동·(4)간접비 **각 합계 = 8-2(1) 총괄표 해당 비목값**.
- [ ] 관계식 유지: E1=A+B+C+D, E2=A+B+D, K=E1+F+G+H+I+S+T, M=K+L.
- [ ] 연구수당 비율(I/E2)·간접비 비율(L/수정직접비) 각주 정의대로 재계산.
- [ ] 기관별 총괄표마다 각주 1)~4) 부착.
- [ ] 수요기업 참여 시 8-1 '그 외 기관 등의 지원금' 열 반영(D3형).
- [ ] (3-1)/(4) 명칭이 `표기명(공식 세세목)` 형식.
- [ ] 참여연구자/학생인건비 현황표의 **기준 차수 명시**(D1=2단계-1차년도형 / D3=1차년도형 택1).
- [ ] 모든 금액표 `(단위 : 천원)`, 셀 사용용도 개조식 명사구.
