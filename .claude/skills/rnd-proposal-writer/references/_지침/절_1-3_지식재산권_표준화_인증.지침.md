# [지침] 절 1-3 「관련 지식재산권·표준화 및 인증기준 현황」 상세

>

**역할**: 과제 관련 **① 지식재산권(특허) 현황(자사/국내/국외), ② 국제표준화 활동, ③ 인증·선급 기준**을 **표 중심**으로 정리해 IP 지형·표준/규제 대응 근거 제시.

## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§2 마커·번호 계층** — 계층 순서: `□ 또는 [대괄호 머리말] → ㅇ(◦) → -(—) → ·`.
- **§3 정량화·근거 표기** — 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.
- **§4 표 서식 관행** — 상당수 절은 자유 서술이 아니라 **정형 표 채우기**다. 표의 열·행 구성과 코드·관계식(예: 예산 K=직접비, M=K+L)을 유지한다.
- **§5 용어·기관명** — 영문 약어는 **최초 등장 시 정의**(예: PWHT, BIM, MSR, IEC, IACS, TRL/CRL).
- **§8 금지사항** — 특정 참조문서의 문장을 **그대로 베끼기**(주제·문구는 새로 작성).

## 골격 지침
- `#### (1) (연구개발기관)` — 컨소시엄 보유 IP·표준·인증  · `ㅇ 지식재산권(특허) 보유 현황` — 표: **No / 출원인 / 출원번호·일자 / 특허명**  · `ㅇ 국제표준화(IEC 등) 활동 현황` — 표: **위원회 / 회의명(TC·WG·PT) / 주제 / 참석자(기관)**  · `ㅇ 국제선급연합회(IACS) 정회원 선급 인증 기준` — 표: **기준명 / 보유기관** (선급 규칙 편·해양구조물 규칙 등)  · `ㅇ 국내 주요 관련 특허` — 표: **특허내용 / 대표도** (상태·출원일·출원번호·등록번호·출원인)
- `#### (2) (참여기관/공동)` — 문서에 따라 생략·통합 가능
- `#### (3) (국외 경쟁 기관)` — `ㅇ 국외 주요 관련 특허`(국내와 동일 표, 출원인 국적 미국/PCT/중국 등 표기), (선택) 국제선급/인증 재정리

## 문서별 변형 지침
- **D3(해상풍력)**: 이 절을 **독립 절로 완비** → 본 절의 1차 모델.
- **D1(디지털트윈)**: 1장에 **독립 1-3 없음**(1-1·1-2로 종료). IP/표준은 타 장에서 다뤄질 수 있음.
- **D11(액화CO2)**: 1-3 미독립 → 표준/규제(IGC Code)·인증 필요성을 **1-2 배경·필요성 안에 편입**해 서술.
- **판단 기준**: 명시적 1-3 절이 요구되면 **D3 골격 기본**. 표준·인증이 필요성 논거 수준이면 D11식으로 1-2에 편입(→ `절_1-2` 참조).

## 문체·표기 지침
- **표 중심·서술 최소**: 표제·설명은 "~현황/~보유/~기준/~적용됨" 명사종결. 서술문은 표를 잇는 최소한만.
- **특허 표기 관행**:  · 보유특허 표 4열(No·출원인·출원번호/일자·특허명). 등록/출원 상태를 일자에 붙임("2018.05.24. 등록", "10-2021-0076980 (2021.06.14)").  · 특허명은 원어 명사구 그대로("일체형 해상풍력 자켓 지지구조물의 시공방법").  · 국내/국외 주요 특허 개별 항목은 `▪특허명(출원인)` 머리 + `- 상태 : 등록`, `- 출원일자 : …`, `- 출원번호 : …`, `- 등록번호 : …` 항목형도 가능.
- **표준화 표기**: 기구·기술위원회 약어 — "IEC TC 88", "MT 12-1", "PT 61400-6", "WG 3", "IECRE". 주제·참석기관(예: 한국선급) 병기.
- **인증/선급 표기**: "국제선급연합회(IACS)", 선급 규칙을 "제1편 …제9편" 편 단위 및 "고정식/이동식 해양구조물 규칙"으로 열거. 코드는 약어 정의(IGC Code, PWHT) [공통원칙 §5].
- **대표도**: `대표도` 열/캡션 자리에 그림 링크 위치만 표시.

## 체크리스트
- [ ] 표준 제목 사용, 유형(독립 D3형 vs 1-2 편입 D11형) 판단.
- [ ] 연구개발기관 보유특허 표(No·출원인·출원번호/일자·특허명) 포함.
- [ ] 국내·국외 주요 특허 구분, 특허 상태·일자·번호 표기.
- [ ] 국제표준화(위원회·항목)·인증/선급 기준 표 포함(해당 시).
- [ ] 영문 약어(IEC·IACS·PCT·관련 Code) 정의 [공통원칙 §5].
- [ ] **존재하지 않는 특허번호·표준항목 지어내지 않음** — 미확정은 "출원예정/확인필요" 자리표시(허위 IP는 치명적, [공통원칙 §8]).
