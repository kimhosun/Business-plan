## 반드시 적용할 공통원칙
- **§1 문체·종결형** — **개조식 명사형 종결**을 기본으로 한다: `~개발 / 구축 / 수립 / 검증 / 확보 / 도출 / 분석 / 함 / 음 / 예정임 / 계획임`.
- **§2 마커·번호 계층** — 계층 순서: `□ 또는 [대괄호 머리말] → ㅇ(◦) → -(—) → ·`.
- **§3 정량화·근거 표기** — 목표·현황·효과에 **수치+단위**를 붙인다: `MW·GW·mm·%·톤·건·명·억원·CAGR` 등.
- **§4 표 서식 관행** — 상당수 절은 자유 서술이 아니라 **정형 표 채우기**다. 표의 열·행 구성과 코드·관계식(예: 예산 K=직접비, M=K+L)을 유지한다.
- **§5 용어·기관명** — 영문 약어는 **최초 등장 시 정의**(예: PWHT, BIM, MSR, IEC, IACS, TRL/CRL).
- **§8 금지사항** — 특정 참조문서의 문장을 **그대로 베끼기**(주제·문구는 새로 작성).

## 골격 지침
- 6-1. 안전조치 이행계획
- 머리표 `[연구소/연구실 단위 안전조치 이행계획]`. **참여기관마다** 아래 **6개 소항목**을 `o` 마커로 순서 고정 반복.
- **o 안전책임자의 지정·운영** — 산업안전보건법 제15조/연구실안전법에 따른 책임자·담당자 지정, 조직체계
- **o 안전관리규정의 제정·운영** — 내부 규정명·근거법령, 일상/정기 점검 운영
- **o 안전관리비 계상** — 근거(연구실안전법 시행령 제17조/시행규칙 제13조), **인건비 총액의 1~2%** 계상, 용도(교육·건강검진·보호구·보험·시설유지)
- **o 안전사고발생시 보고 및 조치** — 보고체계, 중대사고 시 현장보존·조사 절차
- **o 사고 발생 시 대처방안 및 행동요령** — 최초목격자 조치·응급조치·비상연락·2차사고 방지
- **o 안전교육 실시 등** — 정기/신규/특별 교육 시간·주기·대상·방법
- 6-2. 보안조치 이행계획 — 표준 보안점검표(핵심)
- **참여기관마다** 머리표 `ㅇ 주관연구개발기관 : <기관명>` / `ㅇ 공동연구개발기관 : <기관명>` 후, **정부 표준 보안점검 체크표** `구분 | 체크항목 | 결과 체크(√표) | 비고(미실시 사유)` 4열. **5개 구분(고정)**:
- **보안관리체계** — 보안관리규정 제정/적용(*규정명칭*) / 보안조직·자체점검(*담당부서·성명·점검일자*) / 보안교육 연1회 이상(*실시일자*) / 보안사고 방지대책·비상대응계획(*조문·가이드*)
- **참여연구자 관리** — 보안서약서·보안교육 / 해외출장 사전교육·귀국보고 / 퇴직예정자 서약서·자료회수·전산망 차단 / 외국인 영문서약서·출입제한(미참여 시 공란)
- **연구개발 내용/결과 관리** — 무단유출 방지대책 / 보안성 검토 절차 / 기술이전 내부규정 준수
- **연구시설 관리** — 출입권한 차등 / 보안장비·보호구역 지정 / 외부 입주기관 출입통제(없으면 공란)
- **정보통신망 관리** — 내부규정 / 보안책임자 승인항목 구분 / 데이터 백업 / 개인장비(노트북·USB) 인가·관리 / 전산망 보호 HW·SW / 직책·임무별 열람권한 차등
- 각 체크항목 끝에 `O( √ ), X(   )` 표기. **미해당 항목(외국인 미참여·외부 입주기관 없음)은 체크 공란 + 비고에 사유** [공통원칙 §4]. 빈 체크 남발 금지 — `O( √ )`에는 **구체 근거(규정명·담당자·일자)** 부기.
- 6-3. 그 밖의 조치사항 이행계획 (선택 — 현장/실증형)
- 머리표 `[연구개발과제 단위의 안전관리 방안]`. 과제 고유 기술위험을 `o`(또는 `□`)로:
- **o 국내·외 안전사고 사례** — 사례명(발생국) + `·`근본원인. 필요 시 사진/개요/원인/개선방향 표.
- **o 안전기준 준수 방안** — 책임자 선정·매뉴얼·모의훈련·법령준수
- **o 위험성 사전 검토·예측 결과** — 장비/작업별 매뉴얼, 위험요소별 중점 실시사항 표
- **o 수행 중·종료 후 안전점검(일상·정기·특별)·정밀안전진단 계획** — 위험성평가 5단계, 안전작업계획서, KOSHA GUIDE·법정기준 인용
- 단계가 여러 개면 `[1단계_운송설치]`, `[2단계_제작]`처럼 단계별 반복.

## 문서별 변형 지침
- **D1(디지털트윈)** — 6-1 **기관별 블록형**(5곳), 6-2 5개 기관 표 전량, **6-3 없음**. 순수 연구실 안전. → 연구형 중간 밀도.
- **D3(프리파일링자켓)** — 6-1 블록형(7곳), 6-2 표, **6-3 최대 상세**(해상설치·항타·잠수 현장위험, KOSHA GUIDE 다수, 단계별 반복). → 현장 실증형 전형.
- **D11(LCO2탱크)** — 6-1 **소항목별 매트릭스형**(`기관명 | 이행계획` 2열, 10개 기관, 셀 내 `⦁`), 6-2·6-3 간결형. → 다기관·압축.
- **선택 기준**: 기관 소수·상세 서술 → 블록형(D1/D3). 기관 다수·압축 → 매트릭스형(D11). **연구실 실험형** 과제는 D1/D11 밀도·6-3 생략, **해상·건설·중장비 등 현장 실증형**은 D3처럼 6-3을 두껍게.

## 문체·표기 지침
- **법령 인용을 근거로 앞세운다**: 「연구실 안전환경 조성에 관한 법률」, 「산업안전보건법」+시행령/시행규칙 조문번호. 현장형은 KOSHA GUIDE 코드(예: C-2-2012)까지. (일반 출처표기 [공통원칙 §3]보다 조문·코드 특정이 강함.)
- **규정 원문 성격 문장에 한해 서술형 예외**: `~하여야 한다 / ~따른다` 허용. 그 외 항목은 `~운영/계상/지정/실시/수립` 명사형 종결 [공통원칙 §1].
- **내부 규정명·절차서 코드를 구체 명시**로 신뢰성 부여: "안전보건운영관리 절차서(SP-02)", "국가연구개발과제 보안관리 지침(관리번호 11-28, 2021.04.01.시행)". 정식명칭+코드 병기 [공통원칙 §5].
- **점검주기·교육시간을 수치로 못 박음**: 일상점검(매일/매월1회), 정기점검(연2회 이상), 정밀안전진단(2년마다 1회 이상), 자체교육 6h·신규 8h·특별 2h. 안전관리비 `인건비 총액 1~2%`, 중대사고 즉시/24h 이내 조사·5일 이내 경위 제출 [공통원칙 §3].
- 매트릭스형 표 셀 안 마커는 `⦁` [공통원칙 §2].

- [ ] 점검주기·교육시간 등 **정량 수치** 포함 [공통원칙 §3]

- [ ] 전 항목 **개조식 명사형** 종결(규정 인용부만 예외) [공통원칙 §1]
- [ ] **허위 보안 체크(미비 항목 √)·근거 없는 규정명·과장 수치 금지** [공통원칙 §8]
