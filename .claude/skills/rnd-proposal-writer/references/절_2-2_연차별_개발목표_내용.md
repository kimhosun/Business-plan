# 절 2-2. 연차별(단계별) 개발목표 및 개발내용

- 표준 절 제목: `### 2-2. 연구개발 목표 및 내용`
- 대응 스킬: `rnd-write-2-2-annual`
- 성격: 2-1의 최종목표·정량지표를 **단계 → 차년도 → 참여기관 단위로 분해**해 각 기관이 각 연도에 무엇을 목표로 어디까지 수행하는지 개조식으로 나열. 2장에서 **분량이 가장 큰 절**. 문체·마커는 [공통원칙 §1~§2], 기관 표기는 [공통원칙 §5], 정합은 [공통원칙 §7].

## 표준 골격 (3문서 공통)
계층: **[단계] → (n)차년도 → ① 개발 목표 → ② 개발 내용 및 범위 → [기관]별 블록**.

1. (선택) **연차별 연구내용 요약**: 맨 앞 `기관 × 1·2·3·4차년도` 매트릭스로 전 기간 한눈에(D11형). 없으면 생략(D1형).
2. **[1단계]/[2단계]** 머리표(단계가 있으면). 각 단계 아래:
3. **(1) 1차년도 / (2) 2차년도 …**
   - **① 개발 목표**: (D11형) `연구개발기관|개발목표` 표 먼저 + 기관별 서술 / (D1형) `[주관연구개발기관(○○)]` 아래 `o 목표` 나열.
   - **② 개발 내용 및 범위**: `[기관 머리표]` → `o 대항목` → `- 세부내용` 2~3계층. 도식 자리 `< 캡션 >` 표시.
4. 위를 **모든 참여기관(주관 → 공동1..N → 수요기업)**에 반복. 성과 검증만 담당하는 기관은 `o 연구 성과 검증 및 평가` 한 줄.

## 문서별 변형 (기관 블록 밀도 택1)
- **D1 — 목표/내용 분리형 (2단계×각 2차)**: `① 개발 목표`엔 기관별 `o` 한 줄 목표만, `② 개발 내용`에서 `o 대항목 / - 세부`로 상세. 성과검증 기관은 한 줄.
- **D3 — 기관 블록 통합형 (2단계×각 3차)**: 기관 블록에 `개발 목표`(명사형 나열) 두고 곧바로 `o 항목 / - 세부`로 개발내용을 이어 붙임(목표+내용 한 블록). 절별 트리에서 기관마다 개별 파일.
- **D11 — 3분할 + 산출물형 (1단계×4차, 가장 정형)**:
  - `① 개발 목표`: `연구개발기관|개발목표` 표 → 기관별 `o 항목` 아래 **`— 기술현황 : / — 기술개발의 필요성 : / — 기술개발 목표 :`** 3분할.
  - `② 개발 내용 및 범위`: `기관명 + 과제명 (n차년도) – 연구 기반 구축` 헤더 + **`연구내용 | …→…→…`(화살표 흐름) / `산출물 | [n차년도 보고서] …` / `[타 기관 연계] [상대기관] : 전달물`** 3요소.
- **선택 기준**: 목표/내용 분리(D1) / 한 블록 통합(D3) / 기술현황·필요성·목표+산출물·연계 정형화(D11). 과제 규모로 [공통원칙 §6].

## 절 특유 문체 포인트
- 기관 머리표는 `[주관연구개발기관(○○)]` / `[공동연구개발기관1(○○)]` / `[수요기관 ○○ (1)]`. 순서 주관→공동(번호)→수요, 성과검증 전담도 빠짐없이 등장. [공통원칙 §5]
- **각 차년도 목표는 2-1 성능지표의 그 해 목표치와 일치**(임의 변경 금지). [공통원칙 §7]
- 개발내용에 **대상·규모·조건** 명시("폭 300mm 두께 50mm 시험편", "1/15 스케일", "수심 30m 이상").
- **기관 간 인터페이스 명시**: 산출물 수요처·전달물을 `[타 기관 연계]`(D11)로, 또는 검증기관 별도 블록(D1)으로 — 데이터·모듈·시험편 흐름 방향을 드러냄.
- 산출물은 **연차 단위로 귀결**("[1차년도 보고서] …")시켜 2-3 결과물과 연동.
- 표 셀 내 순차흐름 `→`, 병렬 `·` 또는 `①②`. 달성수준 `☞`. [공통원칙 §2]

## 대표 예문 (3문서)
- **D1** 목표/내용 분리: "① 개발 목표 [공동1(인하대)] o 국부 응답 추정 기술 개발·고도화 ／ ② 개발 내용 [공동1(인하대)] o 국부 응답 추정 기술 개발 - 알고리즘 개발 - 전산 프로그램 개발" → 목표 한 줄, 내용 `o/-` 계층.
- **D3** 통합: "[주관(케이베츠)] 개발 목표 · 분리형 최적 시공 절차 / 그립퍼 개념 설계 ／ o 분리형 최적 시공 절차 개념 설계 - 구조물 중량·크기 감소로 국내 장비 사양 최적화" → 목표+내용 한 블록.
- **D11** 3분할: "[주관(중소조선연구원)] o DIC 활용 잔류응력 측정방법 — 기술현황 : 스트레인게이지·XRD 의존, 특정 지점만 측정 — 필요성 : 비접촉식 계측 필요 — 목표 : 2D DIC 측정환경 구축" 및 산출물+연계: "연구내용 | 온도 구간 검토 → 물성 영향 검토 → 소형시험편 제작 · 산출물 | [1차년도 보고서] 물성 라이브러리 · [타 기관 연계] [세진] : 용접 WPS".
