# project — 프로젝트별 자료 저장·관리

각 연구개발(제안) 과제의 자료를 **프로젝트 폴더 하나**로 모아 저장·관리한다.
새 과제를 시작하면 `_템플릿/` 을 통째로 복사해 프로젝트명으로 바꿔 쓴다.

```
project/
  _템플릿/            ← 복사용 표준 템플릿(그대로 두기)
    00_RFP/           공고문·RFP·품목서 원본
    01_참고자료/       참고 논문·보고서·타 사업계획서 등
    02_초안/           작성 중 초안(hwpx/hwp/md/docx)
    03_산출물/         최종 산출물(빌드된 hwpx, 제출본)
    04_이미지/         그림·차트·표 캡처 등 이미지 자산
  <과제명>/           ← _템플릿 을 복사해 만든 실제 프로젝트
```

## 새 프로젝트 만들기

- 탐색기: `_템플릿` 폴더 복사 → 붙여넣기 → 과제명으로 이름 변경.
- 터미널(Git Bash):
  ```bash
  cp -r project/_템플릿 "project/20260812_새과제명"
  ```

## 참고

- 폴더 순서를 유지하려고 번호 접두(00~04)를 쓴다.
- 빈 폴더도 저장소에 남도록 각 폴더에 `.gitkeep` 을 둔다(실제 자료를 넣으면 지워도 무방).
- 웹앱(webapp)이 생성·관리하는 파이프라인 데이터는 별도(`webapp/backend/data/`, git 미추적)다.
  이 `project/` 는 사람이 손으로 모아두는 원본·산출물 보관용이다.
